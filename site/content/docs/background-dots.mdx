# Background Dots

<Member name="background-dots">

The **Background Dots** Sass mixin allows you to easily create a stylish dotted background pattern (also known as **polka dots**).

</Member>

## Arguments

<Arguments of="background-dots" footnote="Using two separate color values together is only possible when the `$diagonal` option is true. See the examples for more.">
  <Argument name="$color" type="list">The color or colors of the dots. Accepts no more than two color values. By default there is only one color, a translucent black.</Argument>
  <Argument name="$size (1em)" type="number (with unit)">The size of the dots. The default value is <code>1em</code>.</Argument>
  <Argument name="$gutter ($size * 5)" type="number (with unit)">The size of the space between the dots. The default value is <code>$size * 5</code>, which means <code>5em</code>.</Argument>
  <Argument name="$diagonal (true)" type="boolean">This option lets you set the line order of the dots. The default value is <code>true</code>.</Argument>
  <Argument name="$image" type="string (quoted)">Accepts the URL of an image. This option helps you add an image underneath the dots to create more stylish design elements.</Argument>
</Arguments>

## Examples

<Example caption="Simply call the mixin without passing any arguments.">
```scss
.element{
  @include background-dots;
}
```
```html
<div class="element sandbox medium"></div>
```
</Example>

<Example caption="Let's play with the `$color` and `$size` arguments.">
```scss
.element{
  @include background-dots(
    $color: pink,
    $size: 10px
  );
}
```
```html
<div class="element sandbox medium"></div>
```
</Example>

<Example caption="You can increase or decrease the space between the dots. Compare the result with example 2.">
```scss
.element{
  @include background-dots(
    $color: pink,
    $size: 10px,
    $gutter: 70px
  );
}
```
```html
<div class="element sandbox medium"></div>
```
</Example>

<Example caption="You can add a second color value as well. Note that the second color only works when the `$diagonal` argument is `true`, and the two colors must be separated by a space.">
```scss
.element{
  @include background-dots(
    $color: red orange,
    $size: 10px
  );
}
```
```html
<div class="element sandbox medium"></div>
```
</Example>

<Example caption="Set the `$diagonal` argument to `false` to make the dots look more linear.">
```scss
.element{
  @include background-dots(
    $color: red,
    $size: 4px,
    $diagonal: false
  );
}
```
```html
<div class="element sandbox medium"></div>
```
</Example>

<Example caption="Now let's add an image and see how sexy this design piece will look!">
```scss
.element{
  @include background-dots(
    $color: rgba(black, 0.1) rgba(green, 0.2),
    $size: 4px,
    $gutter: 20px,
    $image: "/images/backgrounds/03.jpg"
  );
}
```
```html
<div class="sandbox xxlarge example06" style="border-radius:3px; overflow: hidden; background-image: radial-gradient(rgba(0, 0, 0, 0.1) 4px, transparent 0), radial-gradient(rgba(0, 128, 0, 0.2) 4px, transparent 0);background-position: 10px 10px, 40px 40px;background-size: 20px 20px;background-repeat: repeat;position: relative;"></div>
```
</Example>
