# Remove

<Member name="remove">

The **Remove Sass mixin** helps you set the `display` CSS property of an element to `none`. It combines that with CSS media queries to show or hide an element in the document flow at different device widths.

<Hint kind="info">

**Tip:** The usage is very similar to the **Breakpoint** mixin, and it accepts the same arguments.

</Hint>

</Member>

## Arguments

<Arguments of="remove">
  <Argument name="$value" type="number (with unit)">The width, or a key from the breakpoint map. On its own it matches that exact width and no other, and the mixin prints a warning: pass <code>only</code> when that is what you mean. It cannot be a custom property: <code>var()</code> is not evaluated in a <code>@media</code> condition, so the rule would never apply, and the mixin refuses it.</Argument>
  <Argument name="$mode" type="string">Sets the <code>width</code> media feature. Accepts the values <code>only</code>, <code>min</code>, <code>max</code>, and <code>between</code>.</Argument>
</Arguments>

## Examples

<Example resizable caption="Use `min` to remove the element **from a width upwards**, and `max` to remove it **up to a width**. These are the forms you will want most of the time. The bar below is removed from `medium`, 768px, upwards: widen the box past it and it is gone.">
```scss
.element{
  @include remove(min, medium);
}
```
```html
<style>
  body { margin: 0; background: #fafaf8; font: 14px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; color: #2f3937; }
  .element { display: flex; align-items: center; justify-content: space-between; gap: 12px; padding: 12px 16px; background: #2f3937; color: #fafaf8; }
  .element a { padding: 6px 12px; border-radius: 999px; background: #fafaf8; color: #2f3937; font-weight: 600; text-decoration: none; }
  .page { padding: 18px 16px; }
  .page h3 { margin: 0 0 6px; font: 700 18px Inter, ui-sans-serif, system-ui, sans-serif; }
  .page p { margin: 0; color: #657167; }
</style>
<div class="element"><span>Get the app for a faster checkout</span><a href="#">Open</a></div>
<div class="page">
  <h3>Order 2841</h3>
  <p>The bar above belongs to a narrow screen. From 768 upwards it is removed rather than hidden, so it takes no room at all.</p>
</div>
```
</Example>

<Example caption="Two values are a range, and the element is gone between them.">
```scss
.element{
  @include remove(500px, 1024px);
}
```
</Example>

<Hint kind="warning">

**One width on its own is a single pixel.** `remove(500px)` compiles to `@media (width: 500px)`, so the element disappears only when the viewport is exactly 500px wide, and at every other width it stays. To hide it below or above a width, pass `max` or `min` as well. Since 2.2.0 the mixin prints a warning for that form.

</Hint>

<Example caption="If you do want that exact width, `only` says so explicitly. It compiles to the same query as a single value, without the warning.">
```scss
.element{
  @include remove(only, 500px);
}
```
</Example>

<Example caption="The predefined names work in place of a length: `xsmall`, `small`, `medium`, `large`, `xlarge` and `xxl`.">
```scss
.element{
  @include remove(max, medium);
}
```
</Example>

<Example caption="A range of predefined names. One that ends at a name ends just under it, so two ranges that meet there do not overlap.">
```scss
.element{
  @include remove(small, medium);
}
```
</Example>
