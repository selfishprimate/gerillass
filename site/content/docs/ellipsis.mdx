# Ellipsis

<Member name="ellipsis">

The **Ellipsis** Sass mixin helps you truncate text and add an **ellipsis** at the end of it, based on the given `$width` value.

</Member>

## Arguments

<Arguments of="ellipsis">
  <Argument name="$width (100%)" type="number <br/>(with unit)">The <code>max-width</code> of the selected element before its text is truncated. Accepts a length or a percentage, <code>none</code>, <code>min-content</code>, <code>max-content</code>, <code>fit-content</code>, <code>stretch</code>, a CSS-wide keyword, <code>var()</code>, a maths function such as <code>min()</code>, and <code>anchor-size()</code>. Not <code>auto</code>, which <code>max-width</code> does not take.</Argument>
  <Argument name="$display (inline-block)" type="string">Sets the <code>display</code> property of the selected elements. The default value is <code>inline-block</code>. Accepts a display keyword, or two or three in any order, such as <code>inline flex</code>, as long as they name at most one outer type, one inner type and <code>list-item</code>. A vendor keyword such as <code>-webkit-box</code>, a CSS-wide keyword and <code>var()</code> work too, and <code>null</code> leaves <code>display</code> out.</Argument>
</Arguments>

## Examples

<Example caption="Simply call the mixin inside an element's selector to truncate the text in it.">
```scss
.element{
  @include ellipsis;
}
```
```html
<p class="element">Gerillass is a set of Sass mixins and functions built for people who would rather describe what they want than remember how the browser wants it spelled.</p>
```
</Example>

<Example caption="Change the `$width` or `$display` values if you need to.">
```scss
.element{
  @include ellipsis(
    $width: 200px,
    $display: block
  );
}
```
```html
<p class="element">Gerillass is a set of Sass mixins and functions built for people who would rather describe what they want than remember how the browser wants it spelled.</p>
```
</Example>

## What it refuses

A `$display` the browser drops stops the build. Measured in Chrome 152, that is a word that is not a display keyword, and a combination of keywords that names two of a kind, such as `block inline` or `flex grid`. Until 2.3.1 both compiled, and a quoted value such as `"block"` kept its quotes and was dropped as well; it is now written without them.

```scss
.element {
  @include ellipsis(100%, block inline);
}
```
```text
Error: `block inline` is not a valid $display for `ellipsis`: it names two outer display types; pass one of block, inline or run-in. A browser drops the declaration.
```

A `$width` the browser drops stops the build as well. Measured in Chrome 152, `max-width` drops `auto`, a word that is not a sizing keyword, a unitless number other than `0`, a negative length and a length in quotes. Until 2.3.1 these compiled, and the element was left with no width limit.

```scss
.element {
  @include ellipsis(auto);
}
```
```text
Error: `auto` is not a valid $width for `ellipsis`, which sets max-width: it is not a length or one of: min-content, max-content, fit-content, stretch, -webkit-fill-available, -moz-available, none. A browser drops the declaration.
```
