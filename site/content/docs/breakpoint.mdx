# Breakpoint

<Member name="breakpoint">

The **Breakpoint** Sass mixin helps you create scalable media queries and breakpoints using the [@media CSS at-rule](https://developer.mozilla.org/en-US/docs/Web/CSS/@media) in SCSS.

<Hint kind="info">

**Tip:** There are predefined values for breakpoints in the `_map-for-breakpoints.scss` file based on Bootstrap's breakpoint values. **You can add more values here to expand the list or replace existing ones with yours**.

</Hint>

</Member>

## Arguments

<Arguments of="breakpoint" footnote="When you use the `between` option you must pass two values for `width`, and they must be separated by a space. See the [examples](#examples) for more.">
  <Argument name="$mode" type="string">Sets the <code>width</code> media feature. Accepts the values <code>only</code>, <code>min</code>, <code>max</code>, and <code>between</code>.</Argument>
  <Argument name="$value" type="number (with unit)">The width value at which your styles will be applied.</Argument>
</Arguments>

## Examples

<Example caption="Simply call the mixin and **pass a custom value** to it. The code below will apply styles only if your browser's viewport is equal to `320px`.">
```scss
.element{
  @include breakpoint(320px) {
    background-color: green;
  };
}
```
</Example>

<Example caption="If you set the `$mode` option to `only`, you will see that the result is similar to the first example. The code below will apply styles only if your browser's viewport is equal to `1200px`.">
```scss
.element{
  @include breakpoint(only, 1200px) {
    background-color: teal;
  };
}
```
</Example>

<Example caption="Now let's set the `$mode` option to `min` and pass a predefined breakpoint value. If you are a **mobile-first** person, you are going to use this one a lot!">
```scss
.element{
  @include breakpoint(min, medium) {
    background-color: green;
  };
}
```
</Example>

<Example caption="For **desktop-first** arrangements, set the `$mode` option to `max`. This time, let's pass a custom value for the second argument.">
```scss
.element{
  @include breakpoint(max, 1024px) {
    background-color: green;
  };
}
```
</Example>

<Hint kind="info">

**Tip:** You can use **predefined** and **custom** values together if you like.

</Hint>

<Example caption="We can set a range between two values to apply our styles.">
```scss
.element{
  @include breakpoint(between, small 1200px) {
    background-color: green;
  };
}
```
</Example>

<Hint kind="info">

**Important:** Please examine how the predefined breakpoint values line up against each other in the code below.

</Hint>

<Example caption="**Note that** when you use the `between` mode with predefined values, the `max-width` value is always reduced by one. **This prevents the styles you apply from overlapping each other.**">
```scss
.element{
  @include breakpoint(between, small medium) {
    background-color: green;
  };
  @include breakpoint(between, medium large) {
    background-color: blue;
  };
  @include breakpoint(between, large xlarge) {
    background-color: purple;
  };
}
```
</Example>

<Example caption="**Reducing by one** only happens with **predefined** values. When you work with custom values, you don't have to worry about it!">
```scss
.element{
  @include breakpoint(between, small 1199px) {
    background-color: green;
  };
  @include breakpoint(between, 1200px 1400px) {
    background-color: blue;
  };
}
```
</Example>

<Hint kind="info">

The values can be either custom numbers (with a unit) or predefined values.

</Hint>

<Example caption="**Now let's define a range without passing the `between` option.** Simply pass two values and **separate them with a comma**.">
```scss
.element{
  @include breakpoint(320px, 768px) {
    background-color: teal;
  };
}
```
</Example>

<Example caption="Now let's try it with the predefined values just to see that it works.">
```scss
.element{
  @include breakpoint(small, large) {
    background-color: teal;
  };
}
```
</Example>
