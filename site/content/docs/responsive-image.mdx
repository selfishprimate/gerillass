# Responsive Image

<Member name="responsive-image">

The **Responsive Image Sass mixin** helps you make images responsive and change the default `display` CSS property value from `inline` to `block`, which removes the extra space below them.

</Member>

## Examples

<Example caption="Simply call the mixin inside a selector that targets the `<img>` element itself.">
```scss
img {
  @include responsive-image;
}
```
```html
<img src="/images/backgrounds/04.jpg" alt="A photograph filling the width of its container" />
```
</Example>
