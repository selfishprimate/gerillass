# Support

## Something is broken

Open an issue. A compiled example is worth more than a description: the Sass
you wrote, the CSS you got, and the CSS you expected.

- [Report a bug](https://github.com/selfishprimate/gerillass/issues)

Worth checking first: the version you have installed against
[the changelog](https://github.com/selfishprimate/gerillass/blob/main/CHANGELOG.md).
Version 2.0.0 renamed every utility function and replaced two mixins with one,
and [Installation](/docs/installation) has the details under **Coming from
Gerillass 1.x**.
