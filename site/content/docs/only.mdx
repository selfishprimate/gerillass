# Only

<Member name="only">

The **Only** Sass mixin helps you filter elements based on their position among a group of siblings and apply your style rules to **only** those elements. This mixin uses `:first-of-type`, `:last-of-type`, and `:nth-of-type` CSS pseudo-classes.
<Hint kind="info">

You can pass a **string** value to target elements by their `id`, `class`, or `pseudo-class` selector. Or you can pass a **number** (or **multiple numbers** separated by commas) to target items by their index position in the list.

</Hint>

</Member>

## Arguments

<Arguments of="only" footnote="**Important:** Passing multiple arguments only works with numeric values, and the values must be separated by commas.">
  <Argument name="$params…" type="string">The pseudo-class, class, or id selector. Accepts <code>first</code>, <code>last</code>, <code>odd</code>, <code>even</code>, and class or id selectors.</Argument>
  <Argument name="$params…" type="number">The index number of the element in the list, a whole number counted from 1, or from the end when negative. You can also make multiple selections. A number with a unit, a fraction and <code>0</code> are refused.</Argument>
  <Argument name="$of" type="string (quoted)">The selector to count by, such as <code>".card"</code>. Without it the count is <code>:nth-of-type</code>, which counts siblings of the same tag; with it the mixin writes <code>:nth-child(… of .card)</code>, which counts only those. It counts children, so it cannot hold a pseudo-element: <code>":nth-child(2 of ::before)"</code> is dropped by Firefox 156 and Safari 26.6.2 and kept by Chrome 152, where it matches nothing, so it is refused.</Argument>
</Arguments>

## What it refuses

A position has to be a whole number. Until 2.3.1 anything numeric went into the selector as it was, and measured in Chrome 152, `:nth-of-type(10px)` and `:nth-of-type(1.5)` are invalid selectors, so the browser drops the whole rule. In a list of positions one bad value took the good ones with it: `only(1, 10deg)` styled nothing.

```scss
.list-item {
  @include only(10px) {
    color: red;
  }
}
```
```text
Error: `10px` is not a valid position for `only`: a position is a whole number such as `2`, or a multiple of n such as `3n`, and `:nth-of-type(10px)` is an invalid selector, so the browser would drop the rule. Pass a number such as `2`, or `-2` to count from the end.
```

A multiple of `n` is a position too: `only(3n)` writes `:nth-of-type(3n)` and selects every third element. An offset cannot be added, though, because Sass does the arithmetic before the mixin sees it: `only(2n+1)` arrives as `3n` and selects every third element, not the odd ones. For those, pass `odd` or `even`.

`0` is valid CSS but matches nothing, because positions count from 1.

```scss
.list-item {
  @include only(0) {
    color: red;
  }
}
```
```text
Error: `0` is not a valid position for `only`: positions count from 1, so `:nth-of-type(0)` matches nothing. Pass `1` for the first, or `-1` for the last.
```

With several arguments every one of them is a position, so a keyword or a selector goes on its own.

```scss
.list-item {
  @include only(1, "first") {
    color: red;
  }
}
```
```text
Error: `"first"` is not a valid position for `only`: several arguments are all positions, whole numbers such as `1` or `-2`. Pass a keyword such as `first`, or a selector such as `.foo`, on its own.
```

**A bare word is not checked, and a typo there is silent.** The value is
attached to the element, so `only(".card")` writes `.list-item.card` and
`only("-active")` writes `.list-item-active`, the suffix form. That second one
is why a word cannot be refused: appended to a class it continues the class
name, and appended to a tag it makes a type selector for an element nobody has,
which Chrome 152, Firefox 156 and Safari 26.6.2 all keep and none of them ever
matches. A misspelt `first` lands in the second case and styles nothing. Check
the spelling of the keywords.

The mixin narrows the selector it is called in and wraps the styles you give it, so it needs both. At the root, Sass used to fail with "Top-level selectors may not contain the parent selector &", which named neither the mixin nor the fix; with no block it wrote an empty rule that Sass then removed, so the call did nothing and said nothing.

```scss
.list-item {
  @include only(1);
}
```
```text
Error: `only` wraps the styles you pass it, so call it with a block, such as `@include only(1) { color: red; }`.
```

## Counting by something other than the tag

`:nth-of-type` counts an element's siblings **of the same tag**, which is
usually not the thing being counted. Put one stray element in the group and
every number moves:

```html
<div class="grid">
  <div class="note">On sale this week</div>
  <div class="card">A</div>
  <div class="card">B</div>
  <div class="card">C</div>
</div>
```

```scss
.card {
  @include only(1) {
    outline: 2px solid;
  }
}
```

That rule selects **nothing**, because the first `div` in the grid is the note,
and the note is not a card. `only(2)` selects card A. Measured in Chrome 152,
Firefox 156 and Safari 26.6.2, all three the same.

`$of` says what to count, and the numbers mean what they say again:

<Example caption="The same grid, counted by the cards. The note can move, multiply or disappear and the first card is still the first card." listing="<div class=&quot;grid&quot;>
&#32;&#32;<div class=&quot;note&quot;>On sale this week</div>
&#32;&#32;<div class=&quot;card&quot;>A</div>
&#32;&#32;<div class=&quot;card&quot;>B</div>
&#32;&#32;<div class=&quot;card&quot;>C</div>
</div>">
```scss
.card {
  @include only(1, $of: ".card") {
    outline: 2px solid #2f3937;
  }
}
```
```html
<style>
  .grid { display: flex; gap: 10px; font: 14px/1.4 Inter, ui-sans-serif, system-ui, sans-serif; }
  .note { padding: 12px; border-radius: 8px; background: #eefa92; color: #69995d; }
  .card { flex: 1; padding: 12px; border-radius: 8px; background: #f2f2eb; text-align: center; font-weight: 700; }
</style>
<div class="grid">
  <div class="note">On sale this week</div>
  <div class="card">A</div>
  <div class="card">B</div>
  <div class="card">C</div>
</div>
```
</Example>

```scss

    background: #f2f2eb;

  }
}
```

<Hint kind="info">

**`$of` counts, it does not narrow.** `only(".featured")` is a different thing: it adds the selector to the element rather than counting anything, so passing both raises with a message saying which one you want. `:nth-child(… of S)` is in Chrome 111, Firefox 113 and Safari 9, and `CSS.supports` answers true in all three.

</Hint>
