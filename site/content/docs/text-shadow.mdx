# Text Shadow

<Member name="text-shadow">

The **Text Shadow Sass mixin** writes one or more text shadows. Each one is a direction, a colour and a distance, in that order, with an optional blur after them and an optional `true` that fills the gap between the text and the shadow.

</Member>

<Hint kind="warning">

**Changed in Gerillass 4.0.0.** A direction may now be an angle, such as `30deg`, and the eight keywords are the 45 degree steps of that same circle, measured from the top and clockwise, as [Gradient](/docs/gradient) measures them. A shadow now sits the same distance from the text whichever way it points, so a diagonal keyword lands closer than it did: multiply an old diagonal distance by `0.7071` to keep the previous look. The mixin also refuses what browsers drop, and `$step` sets how far apart a filled shadow's layers sit.

</Hint>

## Arguments

<Arguments of="text-shadow" footnote="Separate each shadow with a comma to layer them. See the [examples](#examples) for each form.">
  <Argument name="$direction" type="string, number">Where the shadow goes: <code>top</code>, <code>top-right</code>, <code>right</code>, <code>bottom-right</code>, <code>bottom</code>, <code>bottom-left</code>, <code>left</code>, <code>top-left</code>, or an angle such as <code>30deg</code>, <code>0.25turn</code> or <code>1.2rad</code>, measured from the top and clockwise.</Argument>
  <Argument name="$color" type="color">The shadow's colour. <code>currentColor</code>, <code>var()</code> and <code>color-mix()</code> are all accepted.</Argument>
  <Argument name="$size" type="number, function">How far the shadow sits from the text, such as <code>6px</code>. A <code>var()</code> or <code>calc()</code> is written into a <code>calc()</code> the browser resolves.</Argument>
  <Argument name="$blur" type="number">Optional, after the distance. The default is no blur.</Argument>
  <Argument name="$fill" type="boolean">Optional, last in the group. <code>true</code> fills the gap between the text and the shadow, which is how a long shadow is drawn.</Argument>
  <Argument name="$step" type="number">Named argument for the whole call: how far apart a filled shadow's layers sit, in the same unit as the distance. The default is one pixel, and a fortieth of the distance in a unit this stylesheet cannot convert to pixels, such as <code>rem</code> or <code>ch</code>.</Argument>
</Arguments>

## Examples

<Example caption="A soft shadow under a heading. The three values are the direction, the colour and the distance, in that order.">
```scss
.title {
  @include text-shadow(bottom-right rgb(34 44 37 / 0.35) 6px);
}
```
```html
<style>
  .title { margin: 0; font: 700 34px/1.2 Inter, ui-sans-serif, system-ui, sans-serif; color: #2f3937; }
</style>
<h2 class="title">Shadows, in one line</h2>
```
</Example>

<Example caption="A blur after the distance softens the edge. This is the everyday drop shadow for text over a busy background.">
```scss

  @include text-shadow(bottom rgb(34 44 37 / 0.55) 4px 8px);
}
```

```html
</style>
```

</Example>

## On hover

A `text-shadow` transitions from one layer to another when both states have the **same number of layers**. The distance, the blur and the colour then animate; a state with more layers than the other switches instead of moving. The motion sits inside [Motion Safe](/docs/motion-safe), so a reader who asks for less movement gets the end state with no travel.

<Example caption="A navigation link whose shadow drops and softens on hover. One layer in both states, so the shadow travels.">
```scss
.nav a {
  @include text-shadow(bottom rgb(34 44 37 / 0.25) 2px 2px);

  @include motion-safe {
    transition: text-shadow 0.25s ease;
  }

  &:hover,
  &:focus-visible {
    @include text-shadow(bottom rgb(102 143 128 / 0.45) 8px 10px);
  }
}
```
```html
<style>
  .nav { display: flex; flex-wrap: wrap; gap: 28px; padding: 18px 20px; border-radius: 10px; background: #fafaf8; }
  .nav a { color: #668f80; font: 700 22px/1.2 Inter, ui-sans-serif, system-ui, sans-serif; text-decoration: none; }
</style>
<nav class="nav">
  <a href="#work">Work</a>
  <a href="#studio">Studio</a>
  <a href="#journal">Journal</a>
  <a href="#contact">Contact</a>
</nav>
```
</Example>

<Example caption="A neon sign that brightens when the pointer reaches it. The three layers keep their order and only the blur grows, which is what makes the glow bloom rather than jump.">
```scss
.sign {
  @include text-shadow(
    top #5bc0bb 0px 4px,
    top #5bc0bb 0px 10px,
    top #2f3937 0px 20px

  @include motion-safe {
    transition: text-shadow 0.35s ease;

  &:hover {
    @include text-shadow(
      top #5bc0bb 0px 10px,
      top #5bc0bb 0px 26px,
      top #2f3937 0px 52px
    );
  }
}
```
```html

</style>
<div class="night"><h2 class="sign">Hover me</h2></div>
```
</Example>

<Hint kind="info">

**What the mixin refuses, and why.** Measured in Chrome 152, Firefox 156 and Safari 26.6.2: one broken layer drops the whole `text-shadow` declaration, so a shadow nobody notices is worse than a build that stops. A direction that is neither a keyword nor an angle, a colour a browser does not know, a negative or unitless distance, and a negative blur all raise instead. A distance written as `var()` or `calc()` cannot be filled with `true`, since the number of layers is counted while the stylesheet compiles.

</Hint>
