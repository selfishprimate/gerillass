# Text Shadow

<Member name="text-shadow">

The **Text Shadow Sass mixin** helps you add shadows to text elements. It accepts a comma separated list of shadows, or a single shadow value that can optionally be multiplied. **It provides an easy one-line method.**
<Hint kind="info">

The first three arguments (`$direction`, `$color`, `$size`) are required, and they must be given in that order: @include text-shadow(**bottom red 20px**). You cannot swap these three around.

</Hint>

</Member>

## Arguments

<Arguments of="text-shadow" footnote="**Design Tip:** You can add multi layered shadows to create fancier effects. Just separate each shadow layer with a comma. See the [examples](#examples) for more.">
  <Argument name="$direction" type="string">Sets the direction of the shadow. Accepts <code>top</code>, <code>top-right</code>, <code>right</code>, <code>bottom-right</code>, <code>bottom</code>, <code>bottom-left</code>, <code>left</code>, <code>top-left</code>.</Argument>
  <Argument name="$color" type="color value">Sets the color of the shadow.</Argument>
  <Argument name="$size" type="number (with unit)">Sets how far the shadow will be from the text. When used with <code>$fill</code>, it also determines how many times the shadow will be multiplied.</Argument>
  <Argument name="$blur" type="number (with unit)">Optional. Sets the blur value of the shadow. The default value is <code>null</code>.</Argument>
  <Argument name="$fill" type="boolean">Makes the shadow fill the gap between the text and the shadow. It is optional and <strong>should always come last</strong>. The default value is <code>false</code>.</Argument>
</Arguments>

<Hint kind="danger">

**Important:** If you use the `$fill` argument, it should always come last.

</Hint>

## Examples

<Example caption="Let's start with some basic shadow arrangements.">
```scss
.element{
  @include text-shadow(bottom rgba(black, 0.3) 6px);
}
```
```html
<div class="text-shadow-container">
  <h1 class="element">Text Shadow is Awesome!</h1>
</div>
```
</Example>

<Example caption="Now, let's **add some $blur** to the shadow.">
```scss
.element{
  @include text-shadow(bottom rgba(black, 0.3) 6px 4px);
}
```
```html
<div class="text-shadow-container">
  <h1 class="element">Text Shadow is Awesome!</h1>
</div>
```
</Example>

<Example caption="Now, to understand what `$fill` is for, let's try once more without the `$fill` argument and examine the CSS output.">
```scss
.element{
  @include text-shadow(bottom #5bc0bb 30px);
}
```
```html
<div class="text-shadow-container">
  <h1 class="element">Text Shadow is Awesome!</h1>
</div>
```
</Example>

<Hint kind="info">

It repeats the shadow one step at a time, up to the `$size` value, to **fill the gap between the actual text and the end point of the shadow**.

</Hint>

<Example caption="Now let's pass the `true` value at the end of the argument list and watch the CSS output carefully, because this is where the magic starts.">
```scss
.element{
  @include text-shadow(bottom #5bc0bb 30px true);
}
```
```html
<div class="text-shadow-container">
  <h1 class="element">Text Shadow is Awesome!</h1>
</div>
```
</Example>

<Example caption="You can **add an alpha value to the colors** to soften the shadow.">
```scss
.element{
  @include text-shadow(bottom rgba(#5bc0bb, 0.04) 30px true);
}
```
```html
<div class="text-shadow-container">
  <h1 class="element">Text Shadow is Awesome!</h1>
</div>
```
</Example>

<Example caption="Now let's **add multiple shadow values** with different `$direction`, `$color`, and `$size` values.">
```scss
.element{
  @include text-shadow(
    top yellow 5px, 
    right lightseagreen 15px,
    bottom orange 5px, 
    left pink 15px,
  );
}
```
```html
<div class="text-shadow-container">
  <h1 class="element">Text Shadow is Awesome!</h1>
</div>
```
</Example>

<Example caption="Let's **add an alpha value to the colors** and set the `$fill` option to `true` to make it look sexier!">
```scss
.element{
  @include text-shadow(
    top rgba(yellow, 0.1) 10px true, 
    bottom rgba(orange, 0.1) 10px true, 
    left rgba(pink, 0.1) 10px true,
    right rgba(lightseagreen, 0.1) 10px true
  );
}
```
```html
<div class="text-shadow-container">
  <h1 class="element">Text Shadow is Awesome!</h1>
</div>
```
</Example>

<Example caption="You can **use corners** as well.">
```scss
.element{
  color: pink;
  @include text-shadow(top-left crimson 15px true);
}
```
```html
<div class="text-shadow-container">
  <h1 class="element">Text Shadow is Awesome!</h1>
</div>
```
</Example>

<Hint kind="info">

As long as you don't overdo it, the **Text Shadow** mixin can create marvelous effects.

</Hint>

<Example caption="Here's a good example of how easily you can create artistic effects with **Gerillass**. Just hover over the text below and click on it to see the effect!">
```scss
.element{
  transition: .3s;
  @include text-shadow(left gold 3px true);
  &:hover{
    @include text-shadow(right gold 8px true);
  }
  &:active{
    @include text-shadow(right deepskyblue 8px true);
  }
}
```
```html
<div class="text-shadow-container">
  <h1 class="element example09">Text Shadow is Awesome!</h1>
</div>
```
</Example>

Examples are endless. **Just use your imagination.**
