# Clearfix

<Member name="clearfix">

The **Clearfix** Sass mixin helps you clear floats to prevent broken layouts. It must be applied to the parent element.

</Member>

## Examples

<Example caption="Simply clear floats by calling the mixin inside the parent element's selector.">
```scss
.element{
  @include clearfix;
}
```
</Example>
