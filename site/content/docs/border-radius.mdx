# Border Radius

<Member name="border-radius">

The **Border Radius** Sass mixin helps you round the corners of a selected element using the [border-radius CSS property](https://developer.mozilla.org/en-US/docs/Web/CSS/border-radius). You can pass one value (with a unit) to style all the corners equally, or use the CSS shorthand to style each corner differently. See [the examples](#examples) for more.

</Member>

## Arguments

<Arguments of="border-radius">
  <Argument name="$corner" type="string">Lets you choose which corners of an element you want to style. Accepts the following values: <code>top</code>, <code>top-right</code>, <code>right</code>, <code>bottom-right</code>, <code>bottom</code>, <code>bottom-left</code>, <code>left</code>, <code>top-left</code>, <code>cross-left</code>, <code>cross-right</code>, <code>all</code>. The logical corners <code>start-start</code>, <code>start-end</code>, <code>end-start</code> and <code>end-end</code>, named block side first, and the logical edges <code>inline-start</code>, <code>inline-end</code>, <code>block-start</code> and <code>block-end</code> follow the writing direction instead.</Argument>
  <Argument name="$value" type="number (with unit)">The size of the border radius that will be applied. Accepts a length, a percentage, <code>var()</code> or a maths function. Alone, one radius for every corner can be up to four radii and a slash, as the <code>border-radius</code> property takes; after a corner name, or as one of four radii, it is one radius or two for an elliptical corner. A CSS-wide keyword works as the whole value.</Argument>
</Arguments>

## Examples

<Example caption="Simply pass a value to target all the corners of an element and style them equally.">
```scss
.element{
  @include border-radius(20px);
}
```
```html
<div class="element sandbox medium" style="background-color: #5bc0bb"></div>
```
</Example>

<Example caption="Now let's pass two values. The first one is `top`, to target only the top corners of the selected element, and the second one is `40px`, for the size of the radius.">
```scss
.element{
  @include border-radius(top, 40px);
}
```
```html
<div class="element sandbox medium" style="background-color:#5bc0bb"></div>
```
</Example>

<Hint kind="info">

Just to remind you once more, these are the predefined values you can use to target the corners: `top`, `top-right`, `right`, `bottom-right`, `bottom`, `bottom-left`, `left`, `top-left`, `cross-left`, `cross-right`, `all`.

</Hint>

<Example caption="Now, let's try to target right corners.">
```scss
.element{
  @include border-radius(right, 40px);
}
```
```html
<div class="element sandbox medium" style="background-color:#5bc0bb"></div>
```
</Example>

<Example caption="Now let's try the `cross-left` and `cross-right` values, which let you target the corners diagonally.">
```scss
.element{
  @include border-radius(cross-left, 40px);
}
```
```html
<div class="element sandbox medium" style="background-color:#5bc0bb"></div>
```
</Example>

<Example caption="You can use the CSS shorthand method to pass different radius size values for different corners.">
```scss
.element{
  @include border-radius(25px 50px 100px 150px);
}
```
```html
<div class="element sandbox large" style="background-color:#5bc0bb"></div>
```
</Example>

<Example caption="Now let's **pass four values** again, but this time we are going to **separate them with commas** to try something different.">
```scss
.element{
  @include border-radius(25px, 50px, 100px, 150px);
}
```
```html
<div class="element sandbox large" style="background-color:#5bc0bb"></div>
```
</Example>

<Example caption="For each corner you can pass a second value next to the first one to bend the curve.">
```scss
.element{
  @include border-radius(100px 40px, 50px 20%, 100px 30%, 150px 2rem);
}
```
```html
<div class="element sandbox large" style="background-color:#5bc0bb"></div>
```
</Example>

<Example caption="Use `null` to skip a corner!">
```scss
.element{
  @include border-radius(null, null, 100px 30%, 150px 2rem);
}
```
```html
<div class="element sandbox large" style="background-color:#5bc0bb"></div>
```
</Example>

<Example caption="**Logical corners and edges** follow the writing direction. `inline-start` rounds the side where lines begin: the left in a left-to-right layout, the right in a right-to-left one, from the same rule. Measured in Chrome 152, every logical name renders the same radii as its physical twin in both directions.">
```scss
.tab {
  @include border-radius("inline-start", 16px);
}
```
```html
<div class="tab" dir="ltr" style="height: 48px; margin-bottom: 12px; background: #5bc0bb;"></div>
<div class="tab" dir="rtl" style="height: 48px; background: #5bc0bb;"></div>
```
</Example>

## What it refuses

A radius the browser drops stops the build. Measured in Chrome 152, `border-radius` and the corner properties drop a negative radius, a word such as `auto`, a unit that is not a length, and more radii than they take: four for the whole box, two for one corner. Until 2.3.4 these compiled.

```scss
.element {
  @include border-radius(auto);
}
```
```text
Error: `auto` is not a valid radius for `border-radius`: it is not a length. A browser drops the declaration.
```
