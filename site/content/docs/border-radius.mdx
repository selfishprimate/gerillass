# Border Radius

<Member name="border-radius">

The **Border Radius** Sass mixin helps you round the corners of a selected element using the [border-radius CSS property](https://developer.mozilla.org/en-US/docs/Web/CSS/border-radius). You can pass one value (with a unit) to style all the corners equally, or use the CSS shorthand to style each corner differently. See [the examples](#examples) for more.

</Member>

## Arguments

<Arguments of="border-radius">
  <Argument name="$corner" type="string">Lets you choose which corners of an element you want to style. Accepts the following values: <code>top</code>, <code>top-right</code>, <code>right</code>, <code>bottom-right</code>, <code>bottom</code>, <code>bottom-left</code>, <code>left</code>, <code>top-left</code>, <code>cross-left</code>, <code>cross-right</code>, <code>all</code>. The logical corners <code>start-start</code>, <code>start-end</code>, <code>end-start</code> and <code>end-end</code>, named block side first, and the logical edges <code>inline-start</code>, <code>inline-end</code>, <code>block-start</code> and <code>block-end</code> follow the writing direction instead.</Argument>
  <Argument name="$value" type="number (with unit)">The size of the border radius that will be applied. Accepts a length, a percentage, <code>var()</code> or a maths function. Alone, one radius for every corner can be up to four radii and a slash, as the <code>border-radius</code> property takes; after a corner name, or as one of four radii, it is one radius or two for an elliptical corner. A CSS-wide keyword works as the whole value.</Argument>
</Arguments>

## Examples

<Example caption="One value rounds all four corners, which is the card every layout starts with.">
```scss

  @include border-radius(20px);
}
```

</Example>

## What it refuses

A radius the browser drops stops the build. Measured in Chrome 152, `border-radius` and the corner properties drop a negative radius, a word such as `auto`, a unit that is not a length, and more radii than they take: four for the whole box, two for one corner. Until 2.3.1 these compiled.

```scss
.element {
  @include border-radius(auto);
}
```
```text
Error: `auto` is not a valid radius for `border-radius`: it is not a length. A browser drops the declaration.
```

More radii than the property takes are refused with the count, since a fifth
value drops the whole declaration rather than being ignored.

```scss
.element {
  @include border-radius(10px 20px 30px 40px 50px);
}
```
```text
Error: `10px 20px 30px 40px 50px` is not a valid radius for `border-radius`: it is 5 radii where at most 4 are meant. A browser drops the declaration.
```

And a corner it does not know names every corner and edge it does.

```scss
.element {
  @include border-radius(sideways, 10px);
}
```
```text
Error: `sideways` is not a valid corner for `border-radius`. Pass one of: top, top-right, right, bottom-right, bottom, bottom-left, left, top-left, cross-left, cross-right, all, start-start, start-end, end-start, end-end, inline-start, inline-end, block-start, block-end.
```
