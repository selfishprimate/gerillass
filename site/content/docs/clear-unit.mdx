# Clear Unit

<Member name="clearUnit">

Strips the unit off a number, returning it unitless.

</Member>

## Arguments

<Arguments of="clearUnit">
  <Argument name="$value" type="number">Accepts any number with a unit.</Argument>
</Arguments>

## Examples

<Example caption="A unitless line-height computed from two pixel sizes.">
```scss
@use "sass:math";
.title {
  font-size: 24px;
  line-height: math.div(clearUnit(36px), clearUnit(24px));
}
```
</Example>
