# All Buttons

<Member name="all-buttons">

The **All Buttons** Sass mixin helps you target all the HTML button elements in the DOM, so you can easily apply your style rules.

</Member>

## Arguments

<Arguments of="all-buttons" footnote="You can call the mixin at the root level of your stylesheet to target all the HTML button elements in the DOM, or call it inside a parent selector to target only its children.">
  <Argument name="$pseudo" type="string">Sets the pseudo-class selector for the selected button elements. Accepts the values <code>hover</code>, <code>focus</code>, <code>focus-visible</code>, <code>focus-within</code>, <code>active</code> and <code>disabled</code>.</Argument>
</Arguments>

## Examples

<Example caption="Simply call the mixin at the root level of your stylesheet **to target all the HTML button elements**.">
```scss
@include all-buttons {
  background-color: teal;
  color: white;
}
```
```html
<button type="button">A button element</button>
<input type="submit" value="A submit input" />
<input type="reset" value="A reset input" />
```
</Example>

<Example caption="Now pass the `hover` value as an argument to style all the button elements when they are in the **:hover** state.">
```scss
@include all-buttons(hover) {
  background-color: crimson;
  color: white;
}
```
```html
<button type="button">A button element</button>
<input type="submit" value="A submit input" />
<input type="reset" value="A reset input" />
```
</Example>

<Example caption="Now, let's try it again with all the possible pseudo-class selectors.">
```scss
@include all-buttons {
  background-color: teal;
  color: white;
}
@include all-buttons(hover) {
  background-color: teal;
  color: white;
}
@include all-buttons(focus) {
  background-color: purple;
  color: white;
}
@include all-buttons(active) {
  background-color: blue;
  color: white;
}
@include all-buttons(disabled) {
  background-color: gray;
  color: black;
}
```
```html
<button type="button">Hover, focus and hold me</button>
<button type="button" disabled>Disabled</button>
```
</Example>

<Example caption="Call the mixin inside a selector to target only the button elements inside that selector.">
```scss
.containing-element {
  @include all-buttons {
    background-color: teal;
    color: white;
  }
}
```
```html
<div class="containing-element">
<button type="button">A button element</button>
<input type="submit" value="A submit input" />
<input type="reset" value="A reset input" />
</div>
<button type="button">Outside it, so untouched</button>
```
</Example>

<Example caption="For a focus ring, reach for `focus-visible` rather than `focus`. Measured in Chrome 152 and Firefox 156: a mouse click matches `:focus` but not `:focus-visible`, while arriving with the Tab key matches both, so a ring written for `focus` is shown to everyone who clicks.">
```scss
@include all-buttons("focus-visible") {
  outline: 2px solid currentColor;
  outline-offset: 2px;
}
```
```html
<button type="button">Tab to me</button>
<button type="button">Then to me</button>
```
</Example>

<Hint kind="warning">

**Changed in Gerillass 4.0.0.** The three input types used to be written without `input`, as `[type='button']`, which matches anything carrying that attribute: measured in Chrome 152, Firefox 156 and Safari 26.6.2, `<a type="button">` and a custom element with the same attribute both took the button styles in all three. They are `input[type='button']` and so on now. `input[type='image']`, a submit button drawn as an image, has joined the list: it matched none of the old entries, so it was left out of every rule the mixin wrote.

</Hint>
