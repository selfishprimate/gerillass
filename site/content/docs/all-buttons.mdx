# All Buttons

<Member name="all-buttons">

The **All Buttons** Sass mixin helps you target all the HTML button elements in the DOM, so you can easily apply your style rules.

</Member>

## Arguments

<Arguments of="all-buttons" footnote="You can call the mixin at the root level of your stylesheet to target all the HTML button elements in the DOM, or call it inside a parent selector to target only its children.">
  <Argument name="$pseudo" type="string">Sets the pseudo-class selector for the selected button elements. Accepts the values <code>hover</code>, <code>focus</code>, <code>focus-visible</code>, <code>focus-within</code>, <code>active</code> and <code>disabled</code>.</Argument>
</Arguments>

## Examples

<Example caption="Called at the root of the stylesheet, it reaches every kind of button: a `<button>`, a submit input and a reset input.">
```scss
@include all-buttons {
  padding: 11px 20px;
  border: 0;
  border-radius: 10px;
  background-color: #668f80;
  color: #fff;
  font: 600 14px Inter, ui-sans-serif, system-ui, sans-serif;
}
```
```html
<style>
  body { background: #fafaf8; display: flex; gap: 10px; flex-wrap: wrap; }
</style>
<button type="button">Save changes</button>
<input type="submit" value="Submit" />
<input type="reset" value="Reset" />
```
</Example>

<Example caption="A pseudo-class as the argument styles the same set in that state.">
```scss
@include all-buttons(hover) {
  background-color: #2f3937;
}
```
```html
<style>
  body { background: #fafaf8; display: flex; gap: 10px; flex-wrap: wrap; }
  button, input { padding: 11px 20px; border: 0; border-radius: 10px; background: #668f80; color: #fff; font: 600 14px Inter, ui-sans-serif, system-ui, sans-serif; }
</style>
<button type="button">Hover me</button>
<input type="submit" value="Or me" />
<input type="reset" value="Or me" />
```
</Example>

<Example caption="The states a button needs, one call each, on top of the base rule.">
```scss
@include all-buttons {
  padding: 11px 20px;
  border: 0;
  border-radius: 10px;
  background-color: #668f80;
  color: #fff;
  font: 600 14px Inter, ui-sans-serif, system-ui, sans-serif;
}

@include all-buttons(hover) {
  background-color: #2f3937;
}

@include all-buttons(focus) {
  background-color: #2f3937;
}

@include all-buttons(active) {
  background-color: #2f3937;
}

@include all-buttons(disabled) {
  background-color: #f2f2eb;
  color: #657167;
}
```
```html
<style>
  body { background: #fafaf8; display: flex; gap: 10px; flex-wrap: wrap; }
</style>
<button type="button">Hover, focus and hold me</button>
<button type="button" disabled>Disabled</button>
```
</Example>

<Example caption="Call the mixin inside a selector to target only the button elements inside that selector.">
```scss
.containing-element {
  @include all-buttons {
    padding: 11px 20px;
    border: 0;
    border-radius: 10px;
    background-color: #2f3937;
    color: #fff;
    font: 600 14px Inter, ui-sans-serif, system-ui, sans-serif;
  }
}
```
```html
<style>
  body { background: #fafaf8; font: 14px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; color: #657167; }
  .containing-element { display: flex; gap: 10px; flex-wrap: wrap; padding: 16px; margin-bottom: 12px; border-radius: 14px; background: #fff; box-shadow: 0 4px 14px rgb(34 44 37 / 0.08); }
</style>
<div class="containing-element">
  <button type="button">Inside the card</button>
  <input type="submit" value="Also inside" />
</div>
<button type="button">Outside it, so untouched</button>
```
</Example>

<Example caption="For a focus ring, reach for `focus-visible` rather than `focus`. Measured in Chrome 152 and Firefox 156: a mouse click matches `:focus` but not `:focus-visible`, while arriving with the Tab key matches both, so a ring written for `focus` is shown to everyone who clicks.">
```scss
@include all-buttons("focus-visible") {
  outline: 2px solid #668f80;
  outline-offset: 3px;
}
```
```html
<style>
  body { background: #fafaf8; display: flex; gap: 10px; }
  button { padding: 11px 20px; border: 0; border-radius: 10px; background: #f2f2eb; color: #668f80; font: 600 14px Inter, ui-sans-serif, system-ui, sans-serif; }
</style>
<button type="button">Tab to me</button>
<button type="button">Then to me</button>
```
</Example>

<Hint kind="warning">

**Changed in Gerillass 4.0.0.** The input types are selected with `input` now, so `<a type="button">` and anything else carrying the attribute is left alone, and `input[type='image']` has joined the list.

</Hint>
