# Edge Fade

<Member name="edge-fade">

The **Edge Fade** Sass mixin fades the edge of a scrolling area instead of cutting it off: a carousel of cards that runs past the screen, a feed that scrolls inside a panel, a board that scrolls both ways. It is written as a `mask-image`, and one call covers the gradient, the prefixed twin and the writing direction.

</Member>

<Hint kind="warning">

**New in Gerillass 4.0.0.**

</Hint>

## Arguments

<Arguments of="edge-fade" footnote="A fade on both edges is one gradient; a fade on one edge is two rules, since the second is what makes `start` and `end` follow a right-to-left line.">
  <Argument name="$size" type="number">How far the fade reaches in from the edge, <code>2rem</code> by default. A length, a percentage, a <code>var()</code> or a <code>calc()</code>. A percentage is taken off <code>100%</code> here, so the stop lands in the stylesheet rather than in a <code>calc()</code>.</Argument>
  <Argument name="$edges" type="string"><code>both</code> by default. <code>start</code> fades the edge a line begins at and <code>end</code> the one it ends at, which is the left and the right in a left-to-right language and the other way round in Arabic or Hebrew.</Argument>
  <Argument name="$axis" type="string"><code>inline</code> by default, for a row that scrolls sideways; <code>block</code> for a column that scrolls down; <code>both</code> for an area that does both, which is written as two gradients intersected.</Argument>
</Arguments>

## Before you use it

<Hint kind="danger">

**The fade does not know whether there is anything past it.** A mask is static, so a list that has not been scrolled is still soft at the top, and a row that fits is still soft at both ends. A fade that appears only once the content has moved needs a scroll-driven timeline: measured with `CSS.supports`, Chrome 152 and Safari 26.6.2 have `animation-timeline: scroll()` and Firefox 156 has neither that nor `scroll-timeline`, so that version would be missing in one of the three.

</Hint>

<Hint kind="info">

**A mask fades everything the element paints**, its scrollbar included where the browser draws one inside the box, and it cuts anything painted outside the box, such as a focus ring on a child at the very edge. Both are answered the same way: put the scroller in a wrapper and fade the wrapper.

</Hint>

## What it refuses

```scss
.a {
  @include edge-fade(nonsense);
  @include edge-fade(-2rem);
  @include edge-fade(2rem 3rem);
  @include edge-fade(2rem, sideways);
  @include edge-fade(2rem, both, diagonal);
}
```
```text
Error: `nonsense` is not a valid $size for `edge-fade`: it is not a length. It is how far the fade reaches from the edge, such as `2rem` or `12%`.
Error: `-2rem` is not a valid $size for `edge-fade`: a length below zero does not work here. It is how far the fade reaches from the edge, such as `2rem` or `12%`.
Error: `2rem 3rem` is not a valid $size for `edge-fade`: it is several values where one length is meant. It is how far the fade reaches from the edge, such as `2rem` or `12%`.
Error: `sideways` is not a valid $edges for `edge-fade`. Pass `both`, `start` for the edge a line begins at, or `end` for the one it ends at.
Error: `diagonal` is not a valid $axis for `edge-fade`. Pass `inline` for a row that scrolls sideways, `block` for a column that scrolls down, or `both`.
```
