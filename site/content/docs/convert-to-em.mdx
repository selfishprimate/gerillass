# Convert To Em

<Member name="convertToEm">

Converts a pixel length to em, against a 16px base.

</Member>

## Arguments

<Arguments of="convertToEm">
  <Argument name="$value" type="number (with unit)">Accepts a pixel length.</Argument>
</Arguments>

## Examples

<Example caption="Spacing written in px, emitted in em.">
```scss
.card {
  padding: convertToEm(24px);
  border-radius: convertToEm(8px);
}
```
</Example>
