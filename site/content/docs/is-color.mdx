# Is Color

<Member name="isColor">

Returns the value when every part of it is a colour, and raises when one is not. It is the colour half of a family: [isNumber](/docs/is-number) and [isTime](/docs/is-time) do the same for their own types.

</Member>

## Arguments

<Arguments of="isColor">
  <Argument name="$value" type="color | list">A colour, in any colour space, or a list of them. The value comes back as it was given, with the separator it was given.</Argument>
</Arguments>

## Examples

<Example caption="Checking a colour argument in a mixin of your own. The call stands where the value does, so the guard costs no extra line, and a wrong value stops the build with a message naming it.">
```scss
@mixin badge($color) {
  background-color: isColor($color);
  color: #fff;
}

.badge {
  @include badge(#db504a);
}
```
```html
<style>
  .badge { display: inline-block; padding: 6px 14px; border-radius: 999px; font: 600 13px/1.4 Inter, ui-sans-serif, system-ui, sans-serif; }
</style>
<span class="badge">Checked</span>
```
</Example>

<Example caption="Any colour space counts, and so does `transparent`.">
```scss
.a { color: isColor(oklch(0.52 0.12 160)); }
.b { color: isColor(rgb(219 80 74 / 0.9)); }
.c { background-color: isColor(transparent); }
```
</Example>

## What it refuses

Arguments are checked, so a wrong value stops the build with a message instead of quietly producing the wrong CSS.

```scss
$brand: crimson;
.badge {
  background-color: isColor(brand);
}
```
```text
Error: `brand` is not a valid colour. Pass a colour such as `red` or `#bada55`; `var()` and `currentColor` are not colours this stylesheet can read.
```

`var()` and `currentColor` are refused on purpose, not by oversight. [Tint](/docs/tint) and [Shade](/docs/shade) pass the colour straight to Sass's own `color.mix`, which needs a real colour to mix, so widening this would only move their failure into a Sass internal message. A mixin that writes the colour out rather than mixing it uses the library's looser internal check instead.

```scss
.badge {
  background-color: isColor(var(--brand));
}
```
```text
Error: `var(--brand)` is not a valid colour. Pass a colour such as `red` or `#bada55`; `var()` and `currentColor` are not colours this stylesheet can read.
```
