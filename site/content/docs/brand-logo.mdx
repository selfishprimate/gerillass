# Brand Logo

<Member name="brand-logo">

The **Brand Logo** Sass mixin builds the logo every site header opens with: the
image is the element's background, and the link inside it keeps the brand name
as real text, out of sight behind it. A search engine and a screen reader read
the name, and everybody else sees the logo.

The link fills the box, so tabbing to it draws a focus ring around the whole
logo, and clicking anywhere on it follows the link.

</Member>

<Hint kind="info">

This is one technique for **image replacement**, not the only one. The links at the end of the page compare it with the others.

</Hint>

## Arguments

<Arguments of="brand-logo">
  <Argument name="$width" type="number (with unit)">The width of the logo box. Accepts what <a href="/docs/sizer">Sizer</a> accepts: a length or a percentage, a sizing keyword, a CSS-wide keyword, <code>var()</code> or a maths function.</Argument>
  <Argument name="$height" type="number (with unit)">The height of the logo box. Accepts the same values as <code>$width</code>. The image is fitted inside the box and centred, so it keeps its own proportions whatever the two come to.</Argument>
  <Argument name="$image-url" type="string, function">The logo image, as a path. Optional: leave it out and set the image in the markup instead, which is what a template does when the logo is a variable. A value that already is an image, <code>var()</code>, <code>url()</code>, <code>image-set()</code> or a gradient, is written as it is rather than wrapped in <code>url()</code>. A list, a number, a colour or a boolean is refused.</Argument>
</Arguments>

## Examples

<Example caption="The markup matters as much as the call: a heading holding a link, with the brand name written out inside it. That name is what a search engine indexes and what a screen reader announces; the logo is the background behind it." listing="<h1 class=&quot;brand-logo&quot;>
&#32;&#32;<a href=&quot;/&quot;>Gerillass</a>
</h1>">
```scss
.brand-logo {
  @include brand-logo(
    $width: 196px,
    $height: 42px,
    $image-url: "/images/logo/logo.svg"
  );
}
```
```html
<style>
  body { margin: 0; background: #fafaf8; font: 14px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; }
  .bar { display: flex; align-items: center; justify-content: space-between; gap: 24px; padding: 18px 22px; background: #fff; box-shadow: 0 1px 0 #dee0cd; }
  .bar nav { display: flex; gap: 20px; }
  .bar nav a { color: #657167; text-decoration: none; font-weight: 600; }
  .bar nav a:hover { color: #222c25; }
</style>
<header class="bar">
  <h1 class="brand-logo"><a href="/">Gerillass</a></h1>
  <nav><a href="#">Docs</a><a href="#">Playground</a><a href="#">GitHub</a></nav>
</header>
```
</Example>

<Example resizable hint="Drag the box: the logo shrinks with the header and keeps its proportions, because the image is fitted inside the box rather than stretched across it." caption="`$width` and `$height` take everything [Sizer](/docs/sizer) takes, so a `clamp()` gives the header a logo that scales with it and stops at its natural size.">
```scss
.brand-logo {
  @include brand-logo(
    $width: clamp(110px, 26vw, 196px),
    $height: clamp(24px, 5.6vw, 42px),
    $image-url: "/images/logo/logo.svg"
  );
}
```
```html
<style>
  body { margin: 0; background: #fafaf8; font: 14px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; }
  .bar { display: flex; align-items: center; justify-content: space-between; gap: 16px; padding: 16px 20px; background: #fff; box-shadow: 0 1px 0 #dee0cd; }
  .bar a.cta { flex: none; padding: 8px 14px; border-radius: 8px; background: #222c25; color: #fafaf8; text-decoration: none; font-weight: 600; }
</style>
<header class="bar">
  <h1 class="brand-logo"><a href="/">Gerillass</a></h1>
  <a class="cta" href="#">Install</a>
</header>
```
</Example>

<Example caption="With no `$image-url` the rule is written once and the image comes from the markup, which is what a template does when the logo is a field somebody edits." listing="<h1 class=&quot;brand-logo&quot; style=&quot;background-image: url(/images/logo/logo-with-face.svg)&quot;>
&#32;&#32;<a href=&quot;/&quot;>Gerillass</a>
</h1>">
```scss
.brand-logo {
  @include brand-logo(
    $width: 210px,
    $height: 75px
  );
}
```
```html
<style>
  body { margin: 0; background: #fafaf8; font: 14px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; }
  .bar { display: flex; align-items: center; gap: 24px; padding: 16px 22px; background: #fff; box-shadow: 0 1px 0 #dee0cd; }
</style>
<header class="bar">
  <h1 class="brand-logo" style="background-image: url(/images/logo/logo-with-face.svg)"><a href="/">Gerillass</a></h1>
</header>
```
</Example>

<Example caption="An image the browser chooses is passed through rather than wrapped in `url()`, so a raster logo can ship a version per screen. `var()` works the same way, which is how a theme swaps the file without a second rule.">
```scss
.brand-logo {
  @include brand-logo(
    $width: 196px,
    $height: 42px,
    $image-url: image-set(
      "/images/logo/logo.png" 1x,
      "/images/logo/logo@2x.png" 2x
    )
  );
}

.brand-logo--themed {
  @include brand-logo(196px, 42px, var(--logo));
}
```
</Example>

<Hint kind="warning">

**Changed in Gerillass 4.0.0.** The link fills the logo box instead of being 1px square in its corner, so the focus ring is drawn around the logo rather than as a speck beside it, and `background-size` is `contain` rather than `100%`, so a box wider than the image's own proportions no longer cuts the bottom off the logo. Nothing to do, unless a stylesheet of yours sized the link itself.

</Hint>

## What it refuses

An image that is not one path stops the build. Until 2.3.1 anything went into `url()`: measured in Chrome 152, a list is dropped, and `url(true)` is kept but asks for a file named true, so the logo box stayed empty either way.

```scss
.brand-logo {
  @include brand-logo(120px, 40px, true);
}
```
```text
Error: `true` is not a valid $image-url for `brand-logo`: an image path is a string, and `url(true)` asks for a file of that name, which is never the image. Pass a path as a string, such as `"/img/hero.png"`, or var() or a gradient.
```

A width or height the browser drops stops the build too, the same values [Sizer](/docs/sizer) refuses. Until 2.3.1 they compiled, and the browser dropped the declaration without a word.

```scss
.brand-logo {
  @include brand-logo(120px, 10deg);
}
```
```text
Error: `10deg` is not a valid $height for `brand-logo`: `deg` is not a length unit. A browser drops the declaration.
```
