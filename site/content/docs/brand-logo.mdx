# Brand Logo

<Member name="brand-logo">

The **Brand Logo** Sass mixin helps you create an SEO-friendly logo component for your brand's website using CSS best practices.
<Hint kind="info">

This is a **Gerillass** technique for **image replacement**. There are other methods too. Check out the links at the end of this article to find out more.

</Hint>

</Member>

## Arguments

<Arguments of="brand-logo">
  <Argument name="$width" type="number (with unit)">Sets the width value of the logo image.</Argument>
  <Argument name="$height" type="number (with unit)">Sets the height value of the logo image.</Argument>
  <Argument name="$image-url" type="string, function">Sets the URL of the logo image. Works best with absolute URLs. This argument is optional, so you can also specify the image with the style attribute. A value that already is an image, <code>var()</code>, <code>url()</code>, <code>image-set()</code> or a gradient, is written as it is rather than wrapped in <code>url()</code>. A list, a number, a colour or a boolean is refused.</Argument>
</Arguments>

## Examples

<Hint kind="info">

In this example, I create a logo for **Coolors**. You can use your own brand's logo file and change the logo text if you like.

</Hint>

<Example caption="It is important to use markup similar to the example below. The containing element does not have to be an `<h1>` tag, so feel free to change it depending on the SEO strategy you use on your site." listing="<h1 class=&quot;brand-logo&quot;>
&#32;&#32;<a href=&quot;#&quot;>Coolors</a>
</h1>">
```scss
.brand-logo{
  @include brand-logo(
    $width: 100px,
    $height: 30px,
    $image-url: "https://coolors.co/assets/img/logo.svg"
  );
}
```
```html
Now simply call the mixin as in the example below, and change the argument values to fit your brand logo.

<h1 class="brand-logo example01">
  <a href="#">Coolors</a>
</h1>
```
</Example>

<Hint kind="info">

Note that the `background-image` declaration has disappeared from the generated CSS.

</Hint>

<Example caption="As mentioned before, the `$image-url` argument is optional. With that in mind, let's specify the logo image using the selected element's style attribute." listing="<h1 class=&quot;brand-logo&quot; style=&quot;background-image: url(https://coolors.co/assets/img/logo.svg);&quot;>
&#32;&#32;<a href=&quot;#&quot;>Coolors</a>
</h1>">
```scss
.brand-logo{
  @include brand-logo(
    $width: 100px,
    $height: 30px
  );
}
```
```html
<h1 class="brand-logo" style="background-image: url(https://coolors.co/assets/img/logo.svg);">
  <a href="#">Coolors</a>
</h1>
```
</Example>

## What it refuses

An image that is not one path stops the build. Until 2.3.2 anything went into `url()`: measured in Chrome 152, a list is dropped, and `url(true)` is kept but asks for a file named true, so the logo box stayed empty either way.

```scss
.brand-logo {
  @include brand-logo(120px, 40px, true);
}
```
```text
Error: `true` is not a valid $image-url for `brand-logo`: an image path is a string, and `url(true)` asks for a file of that name, which is never the image. Pass a path as a string, such as `"/img/hero.png"`, or var() or a gradient.
```
