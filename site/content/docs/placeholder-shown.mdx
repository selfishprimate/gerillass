# Placeholder Shown

<Member name="placeholder-shown">

The **Placeholder Shown Sass mixin** helps you style an `<input>` or `<textarea>` element that is currently displaying placeholder text. As soon as the placeholder text disappears (that is, when the user starts typing), the applied style rules go away too.

</Member>

## Examples

<Example caption="Called in a selector, the block styles the field itself while it is empty, which is where an empty state belongs.">
```scss
input {
  @include placeholder-shown {
    border-style: dashed;
    background-color: #fafaf8;
  }
}
```
```html
<style>
  body { background: #fff; font: 14px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; color: #657167; display: grid; gap: 10px; max-width: 340px; }
  input { width: 100%; padding: 12px 14px; border: 1px solid #dee0cd; border-radius: 12px; font: inherit; color: inherit; }
</style>
<input type="text" placeholder="Empty, so the outline is dashed" />
<input type="text" value="Filled in, so it is not" />
```
</Example>

<Example caption="For every field on the page, wrap the call in [All Text Inputs](/docs/all-text-inputs) rather than putting it at the root. The pseudo-class goes on the selector the mixin is called in, so it needs one.">
```scss
@include all-text-inputs {
  @include placeholder-shown {
    border-style: dashed;
    background-color: #fafaf8;
  }
}
```
```html
<style>
  body { background: #fff; font: 14px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; color: #657167; display: grid; gap: 10px; max-width: 340px; }
  input, textarea { width: 100%; padding: 12px 14px; border: 1px solid #dee0cd; border-radius: 12px; font: inherit; color: inherit; }
</style>
<input type="text" placeholder="Empty" />
<textarea placeholder="Also empty" rows="2"></textarea>
```
</Example>

<Hint kind="warning">

**A floating label needs `placeholder=" "`.** `:placeholder-shown` only matches a field that has a placeholder, and in that pattern the field usually shows no placeholder text of its own. A single space, `<input type="text" placeholder=" ">`, keeps the pseudo-class working while showing nothing, which is what makes the label know the field is empty.

</Hint>

## What it refuses

The pseudo-class goes on the selector the mixin is called in, so it needs one.
Until 4.0.0 a call at the root wrote `&:placeholder-shown` and this page said it
styled every field. It does not. Measured in Chrome 152, Firefox 156 and Safari
26.6.2, all three keep the rule and an empty input holds its own border, while
asking the field itself with `matches(":placeholder-shown")` answers true: the
field is empty and the rule simply does not reach it, because a top-level `&` is
`:scope`, which is the document. Dart Sass 1.91 on the command line refuses it
outright, so the same call was a build error or dead CSS depending on how the
stylesheet was compiled.

```scss
@include placeholder-shown {
  border-color: #657167;
}
```
```text
Error: `placeholder-shown` styles the field it is called in, so call it inside a selector, such as `.field { @include placeholder-shown { border-color: gray; } }`. At the root it wrote `&:placeholder-shown`, which styles nothing in any browser. For every field at once, wrap it in `all-text-inputs`.
```

With no block there is nothing to put inside the rule, so Sass removed the rule
and the call did nothing and said nothing.

```scss
.element {
  @include placeholder-shown;
}
```
```text
Error: `placeholder-shown` wraps the styles you pass it, so call it with a block, such as `@include placeholder-shown { border-color: gray; }`.
```
