# Placeholder Shown

<Member name="placeholder-shown">

The **Placeholder Shown Sass mixin** helps you style an `<input>` or `<textarea>` element that is currently displaying placeholder text. As soon as the placeholder text disappears (that is, when the user starts typing), the applied style rules go away too.

</Member>

## Examples

**Type in the fields below.** The pseudo-class tracks whether the field is
empty, not whether it has focus, so the styling stays while you click in and
goes the moment you type a character.

<Example caption="The floating label, which is the pattern this pseudo-class exists for. While the field is empty the label sits on the field's own text line; type and it rises to its place above. The field carries `placeholder=&quot; &quot;`, a single space, because `:placeholder-shown` only matches a field that has a placeholder. The movement is the demo's own `transition`; the mixin writes the two states." listing="<div class=&quot;field&quot;>
&#32;&#32;<input class=&quot;field__input&quot; id=&quot;email&quot; type=&quot;email&quot; placeholder=&quot; &quot;>
&#32;&#32;<label class=&quot;field__label&quot; for=&quot;email&quot;>Email address</label>
</div>">
```scss
.field__input {
  @include placeholder-shown {
    & + .field__label {
      translate: 0 38px;
      font-size: 15px;
      color: #8b9381;
    }
  }
}
```
```html
<style>
  body { display: grid; place-items: center; min-height: 128px; padding: 16px; font: 15px/1.4 Inter, ui-sans-serif, system-ui, sans-serif; }
  .field { position: relative; width: 300px; padding-top: 24px; }
  :where(.field__input) { display: block; width: 100%; padding: 13px 15px; border: 1px solid #dee0cd; border-radius: 10px; background: #fff; font: inherit; color: #2f3937; }
  :where(.field__label) { position: absolute; top: 0; left: 16px; font-size: 12px; line-height: 1.4; font-weight: 600; color: #668f80; transition: translate 0.15s ease, font-size 0.15s ease, color 0.15s ease; pointer-events: none; }
</style>
<div class="field">
  <input class="field__input" id="email" type="email" placeholder=" ">
  <label class="field__label" for="email">Email address</label>
</div>
```
</Example>

<Example caption="Two siblings reading the same state: the format the field wants, set inside it, and a line of help under it. Both belong to an empty field and both go on the first character, which a **Required** marker would not: a field stays required after you fill it. Click into the field and neither moves, which is the difference between this pseudo-class and `:focus`." listing="<div class=&quot;row&quot;>
&#32;&#32;<input class=&quot;row__input&quot; type=&quot;text&quot; placeholder=&quot;Order number&quot;>
&#32;&#32;<span class=&quot;row__format&quot;>1042-7781</span>
&#32;&#32;<p class=&quot;row__help&quot;>You will find it at the top of your receipt.</p>
</div>">
```scss
.row__input {
  @include placeholder-shown {
    & + .row__format {
      visibility: visible;
    }

    & ~ .row__help {
      display: block;
    }
  }
}
```
```html
<style>
  body { display: grid; place-items: center; min-height: 128px; padding: 16px; font: 15px/1.4 Inter, ui-sans-serif, system-ui, sans-serif; }
  .row { position: relative; width: 320px; }
  :where(.row__input) { display: block; width: 100%; padding: 13px 104px 13px 15px; border: 1px solid #dee0cd; border-radius: 10px; background: #fff; font: inherit; color: #2f3937; }
  :where(.row__format) { position: absolute; top: 14px; right: 15px; visibility: hidden; font-size: 13px; line-height: 21px; color: #a8b0a3; }
  :where(.row__help) { display: none; margin: 8px 0 0; font-size: 13px; color: #8b9381; }
</style>
<div class="row">
  <input class="row__input" type="text" placeholder="Order number">
  <span class="row__format">1042-7781</span>
  <p class="row__help">You will find it at the top of your receipt.</p>
</div>
```
</Example>

<Example caption="For every field on the page, wrap the call in [All Text Inputs](/docs/all-text-inputs) rather than putting it at the root. A tint rather than a border, so the focus ring does not sit on top of the thing the example is about: fill either field and its tint goes.">
```scss
@include all-text-inputs {
  @include placeholder-shown {
    background-color: #f2f2eb;
  }
}
```
```html
<style>
  body { font: 15px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; color: #2f3937; display: grid; gap: 10px; max-width: 320px; padding: 16px; }
  :where(input, textarea) { width: 100%; padding: 12px 14px; border: 1px solid #dee0cd; border-radius: 10px; background: #fff; font: inherit; color: inherit; }
</style>
<input type="text" placeholder="Empty, so it is tinted">
<textarea placeholder="This one as well" rows="2"></textarea>
```
</Example>

<Hint kind="warning">

**A floating label needs `placeholder=" "`.** `:placeholder-shown` only matches a field that has a placeholder, and in that pattern the field usually shows no placeholder text of its own. A single space, `<input type="text" placeholder=" ">`, keeps the pseudo-class working while showing nothing, which is what makes the label know the field is empty.

</Hint>

## What it refuses

The pseudo-class goes on the selector the mixin is called in, so it needs one.
Until 4.0.0 a call at the root wrote `&:placeholder-shown` and this page said it
styled every field. It does not. Measured in Chrome 152, Firefox 156 and Safari
26.6.2, all three keep the rule and an empty input holds its own border, while
asking the field itself with `matches(":placeholder-shown")` answers true: the
field is empty and the rule simply does not reach it, because a top-level `&` is
`:scope`, which is the document. Dart Sass 1.91 on the command line refuses it
outright, so the same call was a build error or dead CSS depending on how the
stylesheet was compiled.

```scss
@include placeholder-shown {
  border-color: #657167;
}
```
```text
Error: `placeholder-shown` styles the field it is called in, so call it inside a selector, such as `.field { @include placeholder-shown { border-color: gray; } }`. At the root it wrote `&:placeholder-shown`, which styles nothing in any browser. For every field at once, wrap it in `all-text-inputs`.
```

With no block there is nothing to put inside the rule, so Sass removed the rule
and the call did nothing and said nothing.

```scss
.element {
  @include placeholder-shown;
}
```
```text
Error: `placeholder-shown` wraps the styles you pass it, so call it with a block, such as `@include placeholder-shown { border-color: gray; }`.
```
