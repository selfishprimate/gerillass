# Placeholder Shown

<Member name="placeholder-shown">

The **Placeholder Shown Sass mixin** helps you style an `<input>` or `<textarea>` element that is currently displaying placeholder text. As soon as the placeholder text disappears (that is, when the user starts typing), the applied style rules go away too.

</Member>

## Examples

<Example caption="Simply call the mixin and write your style rules.">
```scss
input{
  @include placeholder-shown{
    background-color: yellow;
  }
}
```
```html
<input type="text" placeholder="Empty, so the placeholder shows" style="width: 100%; margin-bottom: 8px" />
<input type="text" value="Typed in, so it does not" style="width: 100%" />
```
</Example>

<Example caption="When you call the mixin at the root of your stylesheet, it targets all the `<input>` and `<textarea>` elements.">
```scss
@include placeholder-shown{
  background-color: yellow;
}
```
```html
<input type="text" placeholder="Empty" style="width: 100%; margin-bottom: 8px" />
<textarea placeholder="Also empty" rows="2" style="width: 100%"></textarea>
```
</Example>
