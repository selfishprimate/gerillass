# Position

<Member name="position">

The **Position Sass mixin** provides a one-line method to quickly set both the position and the offset properties of a selected element.

</Member>

## Arguments

<Arguments of="position" footnote="To learn more about CSS shorthand properties, check out the links at the end of this page.">
  <Argument name="$position" type="string">Sets the <code>position</code> property of the selected elements. Accepts the CSS values <code>static</code>, <code>relative</code>, <code>fixed</code>, <code>absolute</code>, and <code>sticky</code>. The default value is <code>absolute</code>.</Argument>
  <Argument name="$offsets" type="list">Accepts a list of values to set the offsets of the box edges. It uses the CSS shorthand method. The default value is <code>0</code>. Use <code>null</code> in any position to leave that edge out.</Argument>
  <Argument name="$logical (false)" type="boolean">Pass <code>true</code> for offsets that follow the writing direction. The shorthand order stays the same, and each value goes to the logical twin of its edge: <code>inset-block-start</code>, <code>inset-inline-end</code>, <code>inset-block-end</code> and <code>inset-inline-start</code>. The same choice <code>triangle</code> and <code>border-radius</code> offer with their logical names. <code>null</code> is read as <code>false</code>.</Argument>
</Arguments>

## Examples

<Example caption="Call the mixin without passing any arguments to see the default values that it generates.">
```scss
.element{
  @include position;
}
```
```html
<div style="position: relative; height: 160px; background: #eef2f3; border-radius: 6px">
  <div class="element" style="background: #5bc0bb"></div>
</div>
```
</Example>

<Example caption="Now let's set the position value to `fixed` and leave the offset values as they are." height={180}>
```scss
.element{
  @include position(fixed);
}
```
```html
<div class="element" style="background: #5bc0bb"></div>
```
</Example>

<Example caption="Changing the offset values is easy. Note that multiple offset values must be separated by a space." height={180}>
```scss
.element{
  @include position(fixed, 10px 10px 10px 50px);
}
```
```html
<div class="element" style="background: #5bc0bb"></div>
```
</Example>

<Example caption="You can use the `null` value to skip positioning particular edges of an element.">
```scss
.element{
  @include position(absolute, null 16px 16px 16px);
}
```
```html
<div style="position: relative; height: 160px; background: #eef2f3; border-radius: 6px">
  <div class="element" style="height: 48px; background: #5bc0bb"></div>
</div>
```
</Example>

<Example caption="**Logical offsets** follow the writing direction. `1rem` goes to the start of the line: the left of a left-to-right box and the right of a right-to-left one, from the same rule. Measured in Chrome 152, a physical `left` stayed on the left in both boxes.">
```scss
.badge {
  @include position(absolute, 0.75rem auto auto 0.75rem, $logical: true);
}
```
```html
<div dir="ltr" style="position: relative; height: 72px; background: #eef2f3; border-radius: 6px; margin-bottom: 8px">
  <span class="badge" style="padding: 2px 10px; background: #5bc0bb; color: #fff; border-radius: 999px; font: 500 12px/1.6 system-ui, sans-serif">New</span>
</div>
<div dir="rtl" lang="ar" style="position: relative; height: 72px; background: #eef2f3; border-radius: 6px">
  <span class="badge" style="padding: 2px 10px; background: #5bc0bb; color: #fff; border-radius: 999px; font: 500 12px/1.6 system-ui, sans-serif">جديد</span>
</div>
```
</Example>
