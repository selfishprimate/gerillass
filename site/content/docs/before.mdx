# Before

<Member name="before">

The **Before** Sass mixin writes the element's `::before` rule. A string
becomes its `content`, the name of a `data-` attribute becomes `attr()`, and a
CSS function such as `var()` or `counter()` is passed through as it is rather
than quoted into text.

With no argument it writes `content: ""` in a rule of its own, inside
`:where()`, so a block of styles alone draws something and any `content` you
set elsewhere still wins.

</Member>

## Arguments

<Arguments of="before" footnote="To render the value of a data attribute, pass its name, which must start with `data-`. See the examples for more.">
  <Argument name="$content" type="string, function">You can pass content as a string, or the name of a data attribute such as <code>data-content</code> to render its value. A CSS function, <code>var()</code>, <code>attr()</code>, <code>counter()</code> or <code>counters()</code>, is written as it is rather than quoted into text. With no argument the mixin writes an empty <code>content</code> that anything else sets overrides; see below.</Argument>
</Arguments>

## Examples

<Example caption="A string argument is written straight into `content`, in front of the element's own text.">
```scss
.total {
  @include before("Total: ");
}
```
```html
<style>
  body { background: #fafaf8; font: 15px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; color: #657167; }
  .row { display: flex; justify-content: space-between; width: 260px; padding: 16px 18px; border-radius: 14px; background: #fff; box-shadow: 0 6px 20px rgb(34 44 37 / 0.08); font-weight: 700; }
  .total::before { color: #657167; font-weight: 600; }
</style>
<div class="row"><span class="total"></span><span>$228.00</span></div>
```
</Example>

<Example caption="A declaration block styles the pseudo-element, so the label in front of the note is one rule rather than a second element.">
```scss
.note {
  @include before {
    content: "Note ";
    font-weight: 700;
    font-style: normal;
    color: #69995d;
  }
}
```
```html
<style>
  body { background: #fafaf8; font: 15px/1.6 Inter, ui-sans-serif, system-ui, sans-serif; color: #657167; }
  .note { display: block; max-width: 420px; padding: 14px 16px; border-radius: 12px; background: #fafaf8; color: #69995d; font-style: italic; }
</style>
<em class="note">the trial ends on the first of the month, and nothing is charged before then.</em>
```
</Example>

<Example caption="A `data-` attribute name is read from the markup instead of a string, so each element carries its own text, and a block says how it looks." listing="<div class=&quot;element&quot; data-currency=&quot;&#36;&quot;>200</div>">
```scss
.element {
  @include before("data-currency") {
    margin-right: 2px;
    font-size: .6em;
    vertical-align: top;
    color: #db504a;
  }
}
```
```html
<style>
  .element { font: 600 20px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; color: #2f3937; }
</style>
<div class="element" data-currency="&#36;">200</div>
```
</Example>

## Interface examples

<Example caption="Numbered steps with CSS's own `counter()` function, which the mixin writes as it is rather than quoting it into text. `counter-reset` on the list creates the counter, and `counter-increment` on each step advances it; both are plain CSS." listing="<div class=&quot;steps&quot;>
  <div class=&quot;step&quot;>Install the package</div>
  <div class=&quot;step&quot;>Load it in your stylesheet</div>
  <div class=&quot;step&quot;>Include a mixin</div>
</div>">
```scss
.steps {
  counter-reset: step;
}

.step {
  counter-increment: step;
  @include before(counter(step)) {
    display: inline-flex;
    align-items: center;
    justify-content: center;
    width: 24px;
    height: 24px;
    margin-right: 10px;
    border-radius: 50%;
    background: #222c25;
    color: #fafaf8;
    font-size: 12px;
    font-weight: 600;
  }
}
```
```html
<style>
  .steps { display: grid; gap: 10px; font: 14px/1.4 Inter, ui-sans-serif, system-ui, sans-serif; color: #2f3937; }
  .step { display: flex; align-items: center; }
</style>
<div class="steps">
  <div class="step">Install the package</div>
  <div class="step">Load it in your stylesheet</div>
  <div class="step">Include a mixin</div>
</div>
```
</Example>

<Hint kind="info">

**This `counter()` is not the [Counter](/docs/counter) mixin.** It is the CSS function that reads a counter's value, and `before` passes it through as it does `var()` and `attr()`; the counter itself is reset and incremented by the rules above.

Reach for the Counter mixin when numbering a list is the whole job: it does all three for you. Use `before` with `counter()` when the number is one part of a longer `content`.

</Hint>

<Example caption="An icon from a custom property with `var()`, so each badge sets its own in the markup and one rule draws them all." listing="<span class=&quot;badge ok&quot; style=&quot;--icon: '✓'&quot;>Passed</span>
<span class=&quot;badge warn&quot; style=&quot;--icon: '!'&quot;>Warning</span>
<span class=&quot;badge fail&quot; style=&quot;--icon: '✕'&quot;>Failed</span>">

```html
  .badge.ok { background: #f2f2eb; color: #69995d; }
  .badge.warn { background: #eefa92; color: #69995d; }
  .badge.fail { background: #f2f2eb; color: #db504a; }

<div class="badges">
  <span class="badge ok" style="--icon: '✓'">Passed</span>
  <span class="badge warn" style="--icon: '!'">Warning</span>
  <span class="badge fail" style="--icon: '✕'">Failed</span>
</div>
```
</Example>

## Drawing with no content

<Example caption="A status dot before a label. With no argument the mixin writes `content: &quot;&quot;` for you, so a block of styles alone draws the dot. Until 4.0.0 this drew nothing, because a pseudo-element with no `content` is not rendered.">
```scss
.status {
  @include before {
    display: inline-block;
    width: 8px;
    height: 8px;
    margin-right: 8px;
    border-radius: 50%;
    background: #69995d;
  }
}
```
```html
<style>
  .status { display: inline-flex; align-items: center; font: 500 14px/1 Inter, ui-sans-serif, system-ui, sans-serif; color: #2f3937; }
</style>
<span class="status">All systems operational</span>
```
</Example>

<Example caption="Coloured quotation marks on a `q` element. The browser draws the marks through `::before` and `::after`, and the default would replace them with nothing, so the block keeps them with `open-quote`.">
```scss
q {
  @include before {
    content: open-quote;
    color: #668f80;
  }
}
```
```html
<style>
  p { font: 16px/1.5 Georgia, serif; color: #2f3937; }
</style>
<p>She wrote back: <q>It works in all three browsers.</q></p>
```
</Example>

<Hint kind="warning">

**The default is easy to override, with two exceptions.** If the content only comes from another state, such as `:hover`, write `content: none` in the block and let the state put it back, or the empty box is drawn the rest of the time. On a `q` element it replaces the browser's quotation marks, which the example above keeps with `open-quote`.

</Hint>

## What it refuses

Content that is not a string stops the build. A number, a colour or a boolean
would be written into `content` as text, which is never what was meant, and the
message names the three forms the argument takes.

```scss
.element {
  @include before(42);
}
```
```text
Error: `42` is not a valid $content for `before`. Pass a string to use as the content value, a data- attribute name such as `"data-label"` to render it with attr(), or no argument at all and write the content yourself.
```
