# Before

<Member name="before">

The **Before** Sass mixin helps you generate content or a style element before the actual content of the selected element or elements.

</Member>

## Arguments

<Arguments of="before" footnote="When you want to fetch a value using a custom property, the name of the property must start with the 'data-' prefix. See the examples for more.">
  <Argument name="$content" type="string">You can pass content as a string, or fetch a value using a custom property such as <code>data-content</code>.</Argument>
</Arguments>

## Examples

<Example caption="Simply pass a value as a string.">
```scss
.element{
  @include before("Text to use!");
}
```
</Example>

<Example caption="You can target the `::before` pseudo-element on its own and pass a declaration block.">
```scss
.element{
  @include before{
    content: "Easy to use!";
    font-style: italic;
    color: red;
  };
}
```
</Example>

<Example caption="You can fetch a value using a custom property. One important thing to remember is that the name of the property must start with the 'data-' prefix." listing="<div class=&quot;element&quot; data-currency=&quot;&#36;&quot;>200</div>">
```scss
.element{
  @include before("data-currency");
}
```
```html
<div class="element" data-currency="&#36;">200</div>
```
</Example>

<Example caption="You can pass a value for the CSS content property as a string, and a declaration block between the opening and closing curly braces.">
```scss
.element{
  @include before("data-currency"){
    font-size: .8em;
    color: red;
  };
}
```
</Example>
