# Circle

<Member name="circle">

The **Circle** Sass mixin helps you easily create perfect circle shapes.

</Member>

## Arguments

<Arguments of="circle">
  <Argument name="$size" type="number (with unit)">The size of the circle.</Argument>
</Arguments>

## Examples

<Example caption="Call the mixin inside a selector and pass a number value (with a unit) for the `$size` argument.">
```scss
.element{
  @include circle(150px);
}
```
</Example>
