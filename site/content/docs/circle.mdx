# Circle

<Member name="circle">

The **Circle** Sass mixin writes the three declarations a circle needs: the
size on both axes and a radius that rounds it away.

Pass a length and it is that size. Pass a percentage or a sizing keyword and
the circle follows its container instead, which is the part worth knowing: the
mixin writes `aspect-ratio` there rather than a height, because a height of the
same value measures a different edge and would give you an ellipse.

</Member>

## Arguments

<Arguments of="circle">
  <Argument name="$size" type="number (with unit)">The size of the circle. Accepts what <a href="/docs/sizer">Sizer</a> accepts: a length or a percentage, a sizing keyword, a CSS-wide keyword, <code>var()</code> or a maths function. A length is written as the width and the height; a percentage or a keyword is written as the width with <code>aspect-ratio: 1</code>, since a height of the same value would not match it.</Argument>
</Arguments>

## Examples

<Example caption="A length is the circle's size, on both axes. This one is an avatar beside its name, which is where most circles on a page are.">
```scss
.element {
  @include circle(150px);
}
```

<Hint kind="warning">

**Changed in Gerillass 4.0.0.** A size that is not a length is written as the width with `aspect-ratio: 1` rather than as a height that cannot match it. Measured in a 300&times;100 box, `circle(100%)` used to be 300&times;100 and `circle(auto)` 48&times;14; both are circles now. A length compiles exactly as before.

</Hint>

## What it refuses

A size the browser drops stops the build. Measured in Chrome 152, that is a word that is not a sizing keyword, a unitless number other than `0`, a unit that is not a length, a negative length and a length in quotes. Until 2.3.1 these compiled into a width and height the browser dropped without a word.

```scss
.element {
  @include circle(24);
}
```
```text
Error: `24` is not a valid $size for `circle`: a unitless number is not a length; add a unit, such as `24px`. A browser drops the width and height.
```
