# Sprite

<Member name="sprite">

The **Sprite** Sass mixin helps you apply background images to the selected elements using the CSS sprite technique.

</Member>

## Arguments

<Arguments of="sprite" footnote="To learn more about the `background-position` property values, check out the [links](#related-links) at the end of the page.">
  <Argument name="$image-url" type="string">The URL of the sprite image. <strong>Important:</strong> Don't forget that the image link must be either absolute or relative to the generated CSS file.</Argument>
  <Argument name="$position" type="number | string">Sets the position of the <code>background-image</code>. <strong>Multiple values must be separated by a space.</strong></Argument>
</Arguments>

## Examples

Every example on this page draws from one sheet, `sprite.png`: six frames of a
walk cycle laid out in a row, each 100 by 100, in a 600 by 100 image.

<Hint kind="info">

**Give the element a `width` and a `height`.** The mixin sets the image and the
position; it cannot know how much of the sheet you want. Those two values are
the size of one tile, and you need to know it.

</Hint>

<Example caption="One tile. Pass the sheet and the position of the frame you want, and size the element to match a single tile.">
```scss
.element {
  width: 100px;
  height: 100px;
  @include sprite("/images/docs/sprite.png", 0 0);
}
```
```html
<div class="element"></div>
```
</Example>

<Example caption="Several tiles from the same sheet. The mixin is called once with the sheet, and once per element with only a position: each frame sits 100px further to the left, so the offsets run 0, -100px, -200px and so on.">
```scss
.frame {
  width: 100px;
  height: 100px;
  @include sprite("/images/docs/sprite.png");
}

.frame--1 { @include sprite(0 0); }
.frame--2 { @include sprite(-100px 0); }
.frame--3 { @include sprite(-200px 0); }
.frame--4 { @include sprite(-300px 0); }
```
```html
<div class="frame frame--1"></div>
<div class="frame frame--2"></div>
<div class="frame frame--3"></div>
<div class="frame frame--4"></div>
```
</Example>

<Example caption="Why a sheet in the first place. The six frames are a walk cycle, so stepping the background position across them in one animation plays it, out of a single request rather than six.">
```scss
.element {
  width: 100px;
  height: 100px;
  @include sprite("/images/docs/sprite.png", 0 0);
  animation: walk 0.7s steps(6) infinite;
}

@keyframes walk {
  to {
    background-position: -600px 0;
  }
}
```
```html
<div class="element"></div>
```
</Example>
