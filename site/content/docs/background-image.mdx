# Background Image

<Member name="background-image">

The **Background Image** Sass mixin allows you to apply background images to the selected elements. It gives you an easy, one-line method.

</Member>

## Arguments

<Arguments of="background-image" footnote="Use `null` if you want to skip an argument. See [the examples](#examples) for more.">
  <Argument name="$image-url" type="string">The URL of the background image.</Argument>
  <Argument name="$filter-color" type="color | list">The color or list of colors you want to apply as a filter over the background image. <strong>Multiple color values must be separated by a space.</strong></Argument>
  <Argument name="$filter-direction" type="string">The direction of the gradient. <strong>It only works when you pass multiple color values for the <code>$filter-color</code> argument.</strong> Accepts the values <code>top</code>, <code>top-right</code>, <code>right</code>, <code>bottom-right</code>, <code>bottom</code>, <code>bottom-left</code>, <code>left</code>, and <code>top-left</code>. The default value is <code>top</code>.</Argument>
</Arguments>

## Examples

<Example caption="Simply call the mixin in a selector and pass the URL of the background image.">
```scss
.element{
  @include background-image("/images/backgrounds/07.jpg");
}
```
```html
<div class="element sandbox xlarge"></div>
```
</Example>

<Example caption="Now let's apply a color filter to it by passing a color value for the `$filter-color` argument.">
```scss
.element{
  @include background-image("/images/backgrounds/07.jpg", rgba(255, 204, 153, 0.5));
}
```
```html
<div class="element sandbox xlarge"></div>
```
</Example>

<Hint kind="info">

**Important:** Multiple color values must be separated by a space.

</Hint>

<Example caption="Now let's pass multiple color values for `$filter-color` to make the background image look even more interesting.">
```scss
.element{
  @include background-image("/images/backgrounds/07.jpg", rgba(0, 0, 0, 0.5) rgba(40, 102, 100, 0.8));
}
```
```html
<div class="element sandbox xlarge"></div>
```
</Example>

<Hint kind="info">

**Tip:** The value you pass for `$filter-direction` indicates the position of the final color stop.

</Hint>

<Example caption="Now let's try the `$filter-direction` option. While we do, let's use sharper color transitions to see the effect clearly.">
```scss
.element{
  @include background-image("/images/backgrounds/07.jpg", rgba(0, 128, 128, 0.7) rgba(255, 192, 203, 0.8), right);
}
```
```html
<div class="element sandbox xlarge"></div>
```
</Example>

<Hint kind="info">

**Important:** Please examine the CSS output. When you add a background image to an element using the style attribute, the CSS output is different from the others. This prevents the `background-image` declarations on both sides from overriding each other.

</Hint>

<Example caption="There will be times when you want to **add a background image to an element using the style attribute**, like in the example below. **In those cases, just use `null` to skip the `$image-url` argument.**" listing="<div class=&quot;element&quot; style=&quot;background-image: url(/images/backgrounds/07.jpg)&quot;></div>">
```scss
.element{
  @include background-image(null, rgba(teal, 0.7) rgba(pink, 0.8), right);
}
```
```html
<div class="element sandbox xxlarge example05" style="background-image: url(/images/backgrounds/07.jpg)"></div>
```
</Example>

<Example caption="You are probably wondering why those `position: relative` and `z-index: 1` style rules are applied to the direct children of the selected element. **These rules exist to prevent the color filter from covering the direct children when you add the background image to an element using the style attribute.**

Let's try it with a title placed inside the selected element to see it in action." listing="<div class=&quot;element&quot; style=&quot;background-image: url(/images/backgrounds/07.jpg)&quot;>
&#32;&#32;<h2>A beautiful title text standing over the color filter.</h2>
</div>">
```scss
.element{
  @include background-image(null, rgba(teal, 0.7) rgba(pink, 0.8), right);
}
```
```html
<div class="element sandbox large example06" style="background-image: url(/images/backgrounds/07.jpg)">
  <h2 class="title">A beautiful title text standing over the color filter.</h2>
</div>
```
</Example>
