# Map Deep Get

<Member name="mapDeepGet">

Reads a value out of a nested map by following a chain of keys.

</Member>

## Arguments

<Arguments of="mapDeepGet">
  <Argument name="$map" type="map">Accepts a map.</Argument>
  <Argument name="$keys…" type="string">Accepts one key per level of nesting.</Argument>
</Arguments>

## Examples

<Example caption="Reading two values out of a theme map, without nesting `map.get` calls by hand.">
```scss
$theme: (
  card: (
    padding: 16px,
    radius: 8px,
  ),
);

.card {
  padding: mapDeepGet($theme, card, padding);
  border-radius: mapDeepGet($theme, card, radius);
}
```
</Example>

<Hint kind="info">

**No map the library ships is nested any more.** `$map-for-smartphones` and `$map-for-tablets` held a `width` and a `height` per device until 4.0.0 and now hold the screen as two lengths. This function is for a map of your own.

</Hint>
