# Antialias

<Member name="antialias">

The **Antialias** Sass mixin draws text with greyscale antialiasing instead of subpixel antialiasing, which makes it look thinner. It writes `-webkit-font-smoothing: antialiased` for Chrome and Safari and `-moz-osx-font-smoothing: grayscale` for Firefox.

</Member>

## Arguments

<Arguments of="antialias" footnote="Please check out the links at the end of the page for more information about font smoothing.">
  <Argument name="$value" type="string">Accepts <code>only</code>, which keeps the smoothing on the element the mixin is called in and leaves its descendants alone. With no argument the element and everything inside it are smoothed, and at the root of a stylesheet that is every element on the page. <code>only</code> at the root stops the build, since there is no element to limit it to.</Argument>
</Arguments>

## Examples

<Example caption="The mixin on the lower block and nothing on the upper one, which is the only way to see it: on macOS the lower letters are drawn thinner. Neither property is implemented outside macOS, so on Windows and Linux the two blocks are the same.">
```scss
.element {
  @include antialias;
}
```
```html
<style>
  body { margin: 0; background: #222c25; font: 300 30px/1.35 Inter, ui-sans-serif, system-ui, sans-serif; color: #fafaf8; }
  .stack { display: grid; gap: 2px; }
  .stack > div { padding: 18px 22px; }
  .stack small { display: block; margin-bottom: 4px; font: 600 11px/1 Inter, ui-sans-serif, system-ui, sans-serif; letter-spacing: 0.12em; text-transform: uppercase; color: #bdc488; }
</style>
<div class="stack">
  <div><small>Subpixel, the default</small>Handgloves</div>
  <div class="element"><small>Antialias</small>Handgloves</div>
</div>
```
</Example>

<Example caption="With `only` the smoothing stops at the element: its descendants keep whatever the page draws them with. Without it, as above, they are smoothed too.">
```scss
.element{
  @include antialias(only);
}
```
</Example>

<Example caption="Call the mixin at the root of your stylesheet to target all the HTML elements.">
```scss
@include antialias;
```
</Example>

<Hint kind="warning">

**macOS only, and non-standard.** Neither property is implemented outside macOS, and on macOS only two of the three engines respond:

| | Does the text render differently |
|---|---|
| Chrome 152 | yes |
| Safari 26.6.2 | yes |
| Firefox 156 | no, the image is identical to the byte |

</Hint>

<Hint kind="info">

**Changed in Gerillass 4.0.0.** Called inside a selector with no argument, the descendants are written inside `:where()`, so a rule of your own for one of them wins where it used to lose.

</Hint>

## What it refuses

`only` needs an element to be *only* about, so at the root of a stylesheet it stops the build rather than smoothing the page and hiding the misunderstanding.

```scss
@include antialias(only);
```
```text
Error: `only` has no meaning at the root of a stylesheet, because there is no selector to limit the effect to. Call `antialias("only")` inside a selector, or pass no argument at all.
```

Any other argument is refused with the two forms that work.

```scss
.element {
  @include antialias(bogus);
}
```
```text
Error: `bogus` is not a valid argument for `antialias`. Pass `"only"` inside a selector to affect just that element, or pass no argument at all.
```
