# Antialias

<Member name="antialias">

The **Antialias** Sass mixin draws text with greyscale antialiasing instead of subpixel antialiasing, which makes it look thinner. It writes `-webkit-font-smoothing: antialiased` for Chrome and Safari and `-moz-osx-font-smoothing: grayscale` for Firefox.

</Member>

## Arguments

<Arguments of="antialias" footnote="Please check out the links at the end of the page for more information about font smoothing.">
  <Argument name="$value" type="string">Accepts the <code>only</code> value. Use it when you want to apply the styles to one specific HTML element.</Argument>
</Arguments>

## Examples

<Example caption="The mixin on the lower block and nothing on the upper one, which is the only way to see it: on macOS the lower letters are drawn thinner, and on Windows and Linux neither property does anything, so the two are identical there.">
```scss
.element {
  @include antialias;
}
```
```html
<style>
  body { margin: 0; background: #222c25; font: 300 30px/1.35 Inter, ui-sans-serif, system-ui, sans-serif; color: #fafaf8; }
  .stack { display: grid; gap: 2px; }
  .stack > div { padding: 18px 22px; }
  .stack small { display: block; margin-bottom: 4px; font: 600 11px/1 Inter, ui-sans-serif, system-ui, sans-serif; letter-spacing: 0.12em; text-transform: uppercase; color: #bdc488; }
</style>
<div class="stack">
  <div><small>Subpixel, the default</small>Handgloves</div>
  <div class="element"><small>Greyscale</small>Handgloves</div>
</div>
```
</Example>

<Example caption="Pass the `only` value as an argument to apply the style rules to only one specific HTML element.">
```scss
.element{
  @include antialias(only);
}
```
</Example>

<Example caption="Call the mixin at the root of your stylesheet to target all the HTML elements.">
```scss
@include antialias;
```
</Example>

<Hint kind="warning">

**macOS only, and non-standard.** Neither property does anything on Windows or Linux, and on macOS only two of the three engines respond:

| | Does the text render differently |
|---|---|
| Chrome 152 | yes |
| Safari 26.6.2 | yes |
| Firefox 156 | no, the image is identical to the byte |

</Hint>

<Hint kind="info">

**Changed in Gerillass 4.0.0.** Called inside a selector with no argument, the descendants are written inside `:where()`, so a rule of your own for one of them wins where it used to lose.

</Hint>
