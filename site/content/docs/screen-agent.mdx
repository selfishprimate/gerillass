# Screen Agent

<Member name="screen-agent">

The **Screen Agent Sass mixin** helps you target elements based on different screen resolutions.
<Hint kind="info">

A page that ships two sizes of a picture, one for an ordinary screen and a sharper one for a dense screen, needs a query on the device's pixel ratio to choose between them. That query is what this mixin writes.

</Hint>

</Member>

## Arguments

<Arguments of="screen-agent" footnote="String values must be wrapped in quotation marks.">
  <Argument name="$resolution" type="string,<br/>number (with unit)">Accepts one argument with three possible values that target the screen resolution: <code>1x</code>, <code>2x</code>, and <code>3x</code>. You can also pass a custom resolution in <code>dpi</code>, <code>dpcm</code>, <code>dppx</code> or <code>x</code>. A bare number, a length and a negative resolution are refused, because the query they produce never matches. It cannot be a custom property: <code>var()</code> is not evaluated in a <code>@media</code> condition, and the mixin refuses it.</Argument>
</Arguments>

## Examples

<Example caption="A background image swapped for a sharper file where the screen has the pixels for it.">
```scss
.element{
  background-image: url(https://sample-site.com/images/sample-image-1920x1080.jpg);
  @include screen-agent("2x"){
    background-image: url(https://sample-site.com/images/sample-image-3840x2160.jpg);
  }
}
```
</Example>

<Example caption="A custom density rather than a named one, for a threshold of your own.">
```scss
.element{
  background-color: green;
  @include screen-agent(192dpi){
    background-color: teal;
  }
}
```
</Example>

## What it refuses

A resolution no condition can match stops the build. Measured in Chrome 152, `(min-resolution: 2)`, `(min-resolution: 10px)` and `(min-resolution: -1dppx)` are kept by the browser and never apply, and until 2.3.1 the mixin wrote them without a word.

```scss
.element {
  @include screen-agent(2) {
    color: red;
  }
}
```
```text
Error: `2` is not a valid $resolution for `screen-agent`: `(min-resolution: 2)` would never match. Pass `1x`, `2x`, `3x`, or a resolution such as `2dppx`, `192dpi` or `38dpcm`.
```
