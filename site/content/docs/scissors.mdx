# Scissors

<Member name="scissors">

The **Scissors** Sass mixin helps you **cut off** the corners of an element. It provides an easy one-line method to set the size of the cut and choose the corners you want to apply it to.

<Hint kind="info">

The **first** value selects the `top-left` corner, the **second** the `top-right`, the **third** the `bottom-right`, and the **fourth** the `bottom-left`.

</Hint>

</Member>

## Arguments

<Arguments of="scissors" footnote="You can use `0` or `null` to skip styling the related corner.">
  <Argument name="$corners" type="number (with unit)">Accepts one or four values. The values must be separated by a space. Use the <code>null</code> value to <strong>skip</strong> a corner of the box. Each is a length, a percentage, or a unitless number, which is read as pixels.</Argument>
</Arguments>

## Examples

<Example caption="One value cuts all four corners by the same amount, which is what a coupon looks like.">
```scss
.element{
  @include scissors(30px);
}
```
```html
<style>
  body { background: #f8fafc; font: 14px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; color: #4c0519; }
  .element { display: grid; align-content: center; gap: 4px; padding: 0 28px; background: #fecdd3; }
  .element b { font: 800 26px Inter, ui-sans-serif, system-ui, sans-serif; letter-spacing: -0.02em; }
  .element span { font-weight: 600; color: #9f1239; }
</style>
<div class="element sandbox medium">
  <b>20% off</b>
  <span>Every corner cut, like a coupon</span>
</div>
```
</Example>

<Example caption="Four values, one per corner, in the shorthand order. Zero leaves a corner square.">
```scss
.element{
  @include scissors(30px 30px 0 0);
}
```
```html
<style>
  body { background: #f8fafc; font: 14px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; color: #0f172a; }
  .element { display: grid; align-content: center; gap: 4px; padding: 0 28px; background: linear-gradient(120deg, #a5b4fc, #c4b5fd); color: #1e1b4b; }
  .element b { font: 800 22px Inter, ui-sans-serif, system-ui, sans-serif; }
  .element span { font-weight: 600; opacity: 0.8; }
</style>
<div class="element sandbox medium">
  <b>Row F, seat 12</b>
  <span>Top corners cut, like a ticket stub</span>
</div>
```
</Example>

<Example caption="`null` skips a corner, which is the same as zero written as an intention rather than a number.">
```scss
.element{
  @include scissors(null null 50px 50px);
}
```
```html
<style>
  body { background: #f8fafc; font: 14px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; color: #042f2e; }
  .element { display: grid; align-content: center; gap: 4px; padding: 0 28px; background: #99f6e4; }
  .element b { font: 800 22px Inter, ui-sans-serif, system-ui, sans-serif; }
  .element span { font-weight: 600; color: #0f766e; }
</style>
<div class="element sandbox medium">
  <b>Fragile</b>
  <span>Bottom corners cut, like a shipping label</span>
</div>
```
</Example>

<Hint kind="info">

For some reason, your design component might look different, but I'm sure you get the idea.

</Hint>

<Example caption="A shape with a cut on one side only, over a background that shows the cut." listing="<div class=&quot;element&quot;>
&#32;&#32;<h2>It's a fancy looking title text!</h2>
</div>">
```scss
.element{
  height: 200px;
  display: flex;
  justify-content: center;
  background-color: #5bc0bb;
  @include scissors(0 0 50% 50%);
  h2 {
    color: white;
    font-size: 2.5em; 
    text-align: center;
  }
}
```
```html
<div class="element">
  <h2>It's a fancy looking title text!</h2>
</div>
```
</Example>

## What it refuses

A corner size in a unit that is not a length stops the build. Each size becomes a `polygon()` coordinate, and measured in Chrome 152 a unit such as `deg` or `x` there drops the whole `clip-path`. Until 2.3.1 it compiled.

```scss
.element {
  @include scissors(10deg);
}
```
```text
Error: `10deg` is not a valid corner size: `deg` is not a length unit, and a browser drops the clip-path. Pass a length such as `12px`, or a unitless number which is treated as pixels.
```
