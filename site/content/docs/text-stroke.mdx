# Text Stroke

<Member name="text-stroke">

The **Text Stroke Sass mixin** helps you add a stroke to a text element and style it very easily.

</Member>

## Arguments

<Arguments of="text-stroke" footnote="**Design Tip:** When your stroke color is dark, try making the fallback color the same, so the text looks more consistent with the rest of the design.">
  <Argument name="$color" type="color">Sets the color of the text. The default value is transparent. Each of the three colours takes a colour, <code>currentColor</code>, a system colour, a function such as <code>var()</code> or <code>light-dark()</code>, or a CSS-wide keyword, and <code>null</code> leaves its declaration out.</Argument>
  <Argument name="$stroke-color" type="color">Sets the stroke color of the text. The default value is black.</Argument>
  <Argument name="$fallback-color" type="color">This option is for browsers that do not support text stroke. It prevents the text from disappearing entirely in those browsers. The default value is black.</Argument>
  <Argument name="$stroke-width" type="number (with unit)">Sets the width of the stroke. You can also pass the string values <code>thin</code>, <code>medium</code>, and <code>thick</code>, a CSS-wide keyword, <code>var()</code> or a maths function. Not a percentage or a negative width.</Argument>
</Arguments>

## Examples

<Example caption="Simply call the mixin without passing any arguments.">
```scss
.element {
  @include text-stroke;
}
```
```html
<h1 class="element" style="margin: 0">Text Stroke is Awesome!</h1>
```
</Example>

<Example caption="Now pass some arguments to make the text look sexier!">
```scss
.element {
  @include text-stroke(
    $color: azure,
    $stroke-color: cadetblue,
    $fallback-color: cadetblue,
    $stroke-width: 1px
  );
}
```
```html
<h1 class="element" style="margin: 0">Text Stroke is Awesome!</h1>
```
</Example>

## What it refuses

A colour the browser drops stops the build. Until 2.3.1 each argument was written as it was, and measured in Chrome 152 a word that is not a colour, a quoted colour, a length and two colours side by side are dropped, which here can leave the text transparent with no stroke.

```scss
.element {
  @include text-stroke(black, "red");
}
```
```text
Error: `"red"` is not a valid $color for `text-stroke`: a colour in quotes is text, not a colour. A browser drops the declaration. Pass a colour such as `black`, `currentColor`, or a function such as `var(--stroke)`.
```

A stroke width the browser drops stops the build as well: measured in Chrome 152, a percentage, a negative width and a word other than `thin`, `medium`, `thick` or a CSS-wide keyword. Until 2.3.1 these compiled.

```scss
.element {
  @include text-stroke(black, transparent, red, -1px);
}
```
```text
Error: `-1px` is not a valid $stroke-width for `text-stroke`: a length below zero does not work here. A browser drops the declaration.
```
