# Text Stroke

<Member name="text-stroke">

The **Text Stroke Sass mixin** helps you add a stroke to a text element and style it very easily.

</Member>

## Arguments

<Arguments of="text-stroke" footnote="**Design Tip:** When your stroke color is dark, try making the fallback color the same, so the text looks more consistent with the rest of the design.">
  <Argument name="$color" type="color">Sets the color of the text. The default value is transparent.</Argument>
  <Argument name="$stroke-color" type="color">Sets the stroke color of the text. The default value is black.</Argument>
  <Argument name="$fallback-color" type="color">This option is for browsers that do not support text stroke. It prevents the text from disappearing entirely in those browsers. The default value is black.</Argument>
  <Argument name="$stroke-width" type="number (with unit)">Sets the width of the stroke. You can also pass the string values <code>thin</code>, <code>medium</code>, and <code>thick</code>.</Argument>
</Arguments>

## Examples

<Example caption="Simply call the mixin without passing any arguments.">
```scss
.element {
  @include text-stroke;
}
```
```html
<h1 class="element" style="margin: 0">Text Stroke is Awesome!</h1>
```
</Example>

<Example caption="Now pass some arguments to make the text look sexier!">
```scss
.element {
  @include text-stroke(
    $color: azure,
    $stroke-color: cadetblue,
    $fallback-color: cadetblue,
    $stroke-width: 1px
  );
}
```
```html
<h1 class="element" style="margin: 0">Text Stroke is Awesome!</h1>
```
</Example>
