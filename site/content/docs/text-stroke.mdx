# Text Stroke

<Member name="text-stroke">

The **Text Stroke Sass mixin** outlines text. It takes the width first, then the colour, and a `$style` that says where the outline sits: **outside** the letter, **centred** on its edge, or **hollow**, with the letter left unfilled.

</Member>

<Hint kind="warning">

**Changed in Gerillass 4.0.0.** The arguments are now `$width, $color, $style, $fill`. The old order, `$fallback-color, $color, $stroke-color, $stroke-width`, raises instead of compiling, so every call says so at build time. The default is `hollow` in `currentColor`, which is the look 3.x wrote with no arguments.

</Hint>

<Hint kind="info">

**Why `outside` exists.** `-webkit-text-stroke` centres the outline on the edge of the glyph, so half of it is painted over the letter. Measured at 200px in Chrome 152, Firefox 156 and Safari 26.6.2, a 20px stroke cut the letter's own ink from 11213 pixels to 3174, and a 40px stroke left none of it: the word turns into a blob. `$style: outside` writes `paint-order: stroke fill`, which paints the outline first and the letter over it, and doubles the width, since half of the stroke is then hidden. All three engines do this.

</Hint>

## Arguments

<Arguments of="text-stroke" footnote="Unprefixed `text-stroke` is supported by no engine, checked with `CSS.supports` in all three, so the mixin writes the `-webkit-` properties.">
  <Argument name="$width" type="number">How thick the outline is, such as <code>2px</code>. <code>thin</code>, <code>medium</code> and <code>thick</code> work with <code>center</code> and <code>hollow</code>; a <code>var()</code> or <code>calc()</code> works everywhere.</Argument>
  <Argument name="$color" type="color">The outline's colour. The default is <code>currentColor</code>.</Argument>
  <Argument name="$style" type="string"><code>hollow</code>, the default, leaves the letter unfilled. <code>outside</code> keeps the letterform and puts the outline around it. <code>center</code> writes the property as it is.</Argument>
  <Argument name="$fill" type="color">Optional. The text's own colour. Left out, the element keeps the colour it already has.</Argument>
</Arguments>

## Examples

<Example caption="Hollow display type, the default. One line leaves the letters unfilled and draws their outline in the colour the element already has.">
```scss
.display {
  @include text-stroke(2px);
}
```
```html
<style>
  .display { margin: 0; font: 800 52px/1.1 Inter, ui-sans-serif, system-ui, sans-serif; color: #1d4ed8; letter-spacing: -0.02em; }
</style>
<h2 class="display">Hollow headline</h2>
```
</Example>

<Example caption="An outline around filled letters, over a photograph. `outside` keeps the letterform, which is what makes the text readable at this size rather than turning it into a blob.">
```scss
.hero-title {
  @include text-stroke(3px, #0f172a, outside, #fff);
}
```
```html
<style>
  .hero { padding: 26px 24px; border-radius: 10px; background: linear-gradient(120deg, #22d3ee, #6366f1 55%, #f472b6); }
  .hero-title { margin: 0; font: 800 44px/1.15 Inter, ui-sans-serif, system-ui, sans-serif; }
</style>
<div class="hero"><h2 class="hero-title">Summer issue</h2></div>
```
</Example>

<Example caption="The same width in all three styles, so the difference is easy to see: `outside` keeps the letter whole, `center` eats into it, and `hollow` drops the fill entirely.">
```scss
.a { @include text-stroke(4px, #be123c, outside, #fef3c7); }
.b { @include text-stroke(4px, #be123c, center, #fef3c7); }
.c { @include text-stroke(4px, #be123c, hollow); }
```
```html
<style>
  .styles { display: grid; gap: 10px; }
  .styles p { margin: 0; font: 800 44px/1.15 Inter, ui-sans-serif, system-ui, sans-serif; }
  .styles span { display: block; font: 600 11px/1 monospace; letter-spacing: .08em; color: #71717a; text-transform: uppercase; }
</style>
<div class="styles">
  <div><span>outside</span><p class="a">Outline</p></div>
  <div><span>center</span><p class="b">Outline</p></div>
  <div><span>hollow</span><p class="c">Outline</p></div>
</div>
```
</Example>

</Example>

## On hover

<Example caption="A menu of hollow words that fill in under the pointer. The fill is what changes, so the outline stays put and the letter colours in.">
```scss
.menu a {
  @include text-stroke(2px, #0f172a, hollow);

  @include motion-safe {
    transition: -webkit-text-fill-color 0.25s ease;
  }

  &:hover,
  &:focus-visible {
    @include text-stroke(2px, #0f172a, hollow, #0f172a);
    -webkit-text-fill-color: #facc15;
  }
}
```
```html
<style>
  .menu { display: grid; gap: 4px; padding: 20px; border-radius: 10px; background: #fff7ed; }
  .menu a { font: 800 36px/1.15 Inter, ui-sans-serif, system-ui, sans-serif; color: #0f172a; text-decoration: none; }
</style>
<nav class="menu">
  <a href="#one">Projects</a>
  <a href="#two">Studio</a>
  <a href="#three">Contact</a>
</nav>
```
</Example>

<Example caption="A card title whose outline thickens on hover. Both states pass a length, so the width animates from one to the other.">
```scss
.card-title {
  @include text-stroke(1px, #7c3aed, outside, #faf5ff);

  @include motion-safe {
    transition: -webkit-text-stroke-width 0.25s ease;
  }

  .card:hover & {
    @include text-stroke(4px, #7c3aed, outside, #faf5ff);
  }
}
```
```html
<style>
  .card { padding: 24px; border-radius: 10px; background: #2e1065; cursor: pointer; }
  .card-title { margin: 0; font: 800 44px/1.15 Inter, ui-sans-serif, system-ui, sans-serif; }
</style>
<div class="card"><h2 class="card-title">Hover me</h2></div>
```
</Example>

<Hint kind="danger">

**Keep the text readable.** A hollow outline at a small size, or a thin one in a low contrast colour, is hard to read, and an outline is not a substitute for contrast between the text and its background. Reach for `hollow` on display type, and for `outside` when the text has to be read over a photograph.

</Hint>
