# Font Face

<Member name="font-face">

The **Font Face** Sass mixin helps you generate a cross-browser compatible @font-face declaration.
<Hint kind="info">

**Important:** The mixin must be called at the root level of your stylesheet.

</Hint>

</Member>

## Arguments

<Arguments of="font-face" footnote="To learn more about the **font-weight** property values, check out the [links](#related-links) at the end of the article.">
  <Argument name="$font-family" type="string">Sets the name of the <code>font-family</code>. It cannot be a custom property: a <code>@font-face</code> rule drops <code>font-family: var(--f)</code>, and without a family the font is never used. A quoted string is a name, so <code>"var(--f)"</code> in quotes is kept as one. The same rule drops an unquoted generic family or keyword such as <code>sans-serif</code>, <code>serif</code>, <code>system-ui</code> or <code>inherit</code>, and <code>env()</code> or <code>attr()</code>, so those are refused too. Quote the name if a font really is called that.</Argument>
  <Argument name="$file-path" type="string">Sets the path and the name of the font file. The file name must be written without the extension. It cannot be a custom property: the path is written into <code>url()</code> as text.</Argument>
  <Argument name="$font-style" type="string">Sets the <code>font-style</code> property. The default value is <code>normal</code>. If there is an <code>italic</code> version of the font, you can set the value to <code>italic</code> or <code>oblique</code>. A quoted value such as <code>"italic"</code> is written without its quotes, which a browser would drop. It cannot be a custom property.</Argument>
  <Argument name="$font-weight" type="number">Sets the weight of the font. The default value is <code>400</code>. Accepts <code>100</code>, <code>200</code>, <code>300</code>, <code>400</code>, <code>500</code>, <code>600</code>, <code>700</code>, <code>800</code>, and <code>900</code>, or a range such as <code>160 700</code> for a variable font. A quoted value is written without its quotes. It cannot be a custom property, even as one end of a range: measured in Chrome 152, a <code>@font-face</code> rule dropped <code>var()</code> in <code>font-family</code>, <code>font-style</code> and <code>font-weight</code>.</Argument>
  <Argument name="$file-formats" type="string | list">Sets the font file formats you want to include. The default value is <code>eot woff2 woff ttf svg</code>. A format outside that list is refused with an error. Pass only the formats you have files for: a bundler such as Parcel resolves every <code>url()</code> and fails on a missing file.</Argument>
  <Argument name="$font-display" type="string">Sets the <code>font-display</code> descriptor, which decides what the text does while the font is still loading. Accepts <code>auto</code>, <code>block</code>, <code>swap</code>, <code>fallback</code> and <code>optional</code>. The default is <code>null</code>, which leaves it out, so the browser's own behaviour applies.</Argument>
</Arguments>

## Examples

<Example caption="Let's call the mixin and pass values for the required arguments: `$font-family` and `$file-path`.">
```scss
@include font-face("Fanwood Text", "fonts/fanwood-text/fanwood-text-regular");
```
</Example>

<Example caption="Now let's add the `italic` version of the family.">
```scss
@include font-face("Fanwood Text", "fonts/fanwood-text/fanwood-text-regular", italic);
```
</Example>

<Example caption="Now let's add the `bold` version of the `Fanwood Text` font-family (if there is one) by passing `700` for the `$font-weight` argument.">
```scss
@include font-face("Fanwood Text", "fonts/fanwood-text/fanwood-text-bold", 700);
```
</Example>

<Example caption="If you pass values for both the `$font-style` and `$font-weight` arguments, the `$font-weight` value should always come last, unless you also pass a value for `$file-formats`.">
```scss
@include font-face("Fanwood Text", "fonts/fanwood-text/fanwood-text-bold-italic", italic, 700);
```
</Example>

<Hint kind="info">

Things get trickier when you want to pass a value for `$file-formats`. The examples below show the ways to do it.

</Hint>

<Example caption="Suppose you only have three file formats: `woff2`, `woff`, and `ttf`.">
```scss
@include font-face("Fanwood Text", "fonts/fanwood-text/fanwood-text-regular", woff2 woff ttf);
```
</Example>

<Example caption="If you want to pass values for all the arguments, the order must be `$font-family`, `$file-path`, `$font-style`, `$font-weight`, `$file-formats`, like in the example below.">
```scss
@include font-face("Fanwood Text", "fonts/fanwood-text/fanwood-text-bold-italic", italic, 700, woff2 woff);
```
</Example>

<Hint kind="info">

**Tip:** Do you know what is beautiful about named arguments? **They are order-independent**, which makes them very useful when it is hard to stick to the argument order.

</Hint>

<Example caption="If you are having trouble passing the arguments by position, try **named arguments**.">
```scss
@include font-face (
  $font-family: "Fanwood Text", 
  $file-path: "fonts/fanwood-text/fanwood-text-bold-italic",
  $font-style: italic, 
  $font-weight: 700,
  $file-formats: eot woff2 woff
);
```
</Example>

<Example caption="Try changing the order of the arguments. Whatever order you use, the result is the same.">
```scss
@include font-face (
  $font-weight: 700,
  $font-style: italic,
  $file-formats: eot woff2 woff, 
  $font-family: "Fanwood Text",
  $file-path: "fonts/fanwood-text/fanwood-text-bold-italic",
);
```
</Example>

<Example caption="Now let's use the `@content` directive to pass a content block into the mixin.">
```scss
@include font-face ("Fanwood Text", "fonts/fanwood-text/fanwood-text-regular") {
  font-display: fallback;
}
```
</Example>

If you don't have all the font varieties, or you have a font you want to convert into a **web font** (embeddable with @font-face), try **Font Squirrel**'s [Webfont Generator](https://www.fontsquirrel.com/tools/webfont-generator).

<Example caption="A **variable font** in one file. The weight range is written through as it is, and `$font-display: swap` shows the text in a fallback font until the file arrives, rather than hiding it.">
```scss
@include font-face(
  "Readex Pro",
  "/fonts/readex-pro",
  $font-weight: 160 700,
  $file-formats: woff2,
  $font-display: swap
);
```
</Example>
