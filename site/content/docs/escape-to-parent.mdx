# Escape to Parent

<Member name="escape-to-parent">

The **Escape to Parent** Sass mixin writes the rule again with another selector attached to the **outermost element** it is nested in. A theme or a state class higher up the page can then switch what the rule does, while the rule itself stays in the component it belongs to.

</Member>

<Hint kind="warning">

**Changed in Gerillass 4.0.0.** The selector is attached with Sass's own selector functions rather than pasted on as text, which used to drop the theme from the second half of `.c, .d`, turn `ul li` into `.themeul li`, and split a list argument. The CSS a call writes can change; see the migration guide.

</Hint>

## Arguments

<Arguments of="escape-to-parent" footnote="The selector is a quoted string. Pass several at once by separating them with commas.">
  <Argument name="$selector" type="string (quoted)">A selector to attach to the outermost element, usually a <code>class</code> or an <code>id</code>. Several, separated by commas, are each attached in turn, and a descendant selector such as <code>"body.theme .inner"</code> keeps its ancestors.</Argument>
</Arguments>

## Examples

<Example caption="A panel that follows a theme class on the element around it. Both rules are inside the component, and neither one is repeated under a theme selector somewhere else in the stylesheet." listing="<div class=&quot;panel&quot;>
&#32;&#32;<span class=&quot;price&quot;>$29</span>
</div>
<div class=&quot;panel theme-dark&quot;>
&#32;&#32;<span class=&quot;price&quot;>$29</span>
</div>">
```scss
.panel {
  @include escape-to-parent(".theme-dark") {
    background: #222c25;
    border-color: #2f3937;
  }

  .price {
    color: #668f80;

    @include escape-to-parent(".theme-dark") {
      color: #fafaf8;
    }
  }
}
```
```html
<style>
  .demo-row { display: flex; gap: 16px; font: 15px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; }
  .panel { flex: 1; padding: 24px; border: 1px solid #dee0cd; border-radius: 10px; background: #ffffff; text-align: center; }
  .price { font-size: 24px; font-weight: 700; }
</style>
<div class="demo-row">
  <div class="panel"><span class="price">$29</span></div>
  <div class="panel theme-dark"><span class="price">$29</span></div>
</div>
```
</Example>

<Example caption="The same thing for a state rather than a theme. The class goes on the menu, and the rule for the item reads it from inside the item's own block." listing="<nav class=&quot;menu&quot;>
&#32;&#32;<span class=&quot;item&quot;>Settings</span>
</nav>
<nav class=&quot;menu is-open&quot;>
&#32;&#32;<span class=&quot;item&quot;>Settings</span>
</nav>">
```scss
.menu .item {
  opacity: 0.45;

  @include escape-to-parent(".is-open") {
    opacity: 1;
    font-weight: 700;
  }
}
```
```html
<style>
  .demo-row { display: flex; gap: 16px; font: 15px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; }
  .menu { flex: 1; padding: 20px; border-radius: 10px; background: #fafaf8; text-align: center; }
</style>
<div class="demo-row">
  <nav class="menu"><span class="item">Settings</span></nav>
  <nav class="menu is-open"><span class="item">Settings</span></nav>
</div>
```
</Example>

<Example caption="Several selectors at once. Each one is attached in turn, so two themes that share a rule take one include rather than two." listing="<div class=&quot;card theme-dark&quot;>Dark</div>
<div class=&quot;card theme-dim&quot;>Dim</div>">
```scss
.card {
  color: #668f80;

  @include escape-to-parent(".theme-dark, .theme-dim") {
    color: #fafaf8;
  }
}
```
```html
<style>
  .demo-row { display: flex; gap: 16px; font: 15px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; font-weight: 600; }
  .card { flex: 1; padding: 24px; border-radius: 10px; text-align: center; background: #f2f2eb; }
  .theme-dark { background: #222c25; }
  .theme-dim { background: #657167; }
</style>
<div class="demo-row">
  <div class="card theme-dark">Dark</div>
  <div class="card theme-dim">Dim</div>
</div>
```
</Example>

<Hint kind="info">

**Where the selector lands.** On the outermost element of the rule, as one compound: `.a .b` gives `.theme.a .b`, not `.theme .a .b`, and `ul li` gives `ul.theme li`, with the element written first as CSS requires. For a class that sits on an **ancestor** of that element, pass the ancestor with it, such as `"body.theme .inner"`, which keeps its own ancestors and attaches only its last part.

</Hint>

<Hint kind="danger">

**What it refuses.** Two element selectors cannot match the same element, so `ul li` with `"html"` or `"body.theme"` raises rather than writing the `htmlul li` that matches nothing. A call with no `$selector`, a call outside any rule, an `&` in the argument, an empty string and a selector ending in a combinator all raise as well.

</Hint>
