# Center

<Member name="center">

The **Center** Sass mixin allows you to center elements (**those with a `position` value of either `absolute` or `fixed`**) on both the horizontal and vertical axes.
<Hint kind="info">

**Important:** You must set either `position: absolute` or `position: fixed` on the selected element to make this mixin work correctly. **The parent element you are centering within must have a `position` value other than `static`.**

</Hint>

<Hint kind="info">

**`transform` stays yours.** Since 4.0.0 the mixin writes the individual `translate` property instead, so a `transform` of your own, a rotation, a hover that scales, composes with the centring rather than replacing it. Until then a single `transform: scale(1.05)` on hover moved the element off centre: measured in Chrome 152, Firefox 156 and Safari 26.6.2, a 100 by 50 element centred in a 400 by 200 box sat 50px right and 25px below the middle in all three, and now stays where it is.

</Hint>

</Member>

## Arguments

<Arguments of="center" footnote="Pass the `both` value to center an element on both the horizontal and vertical axes, or pass nothing at all.">
  <Argument name="$axis" type="string">Sets the axis of the alignment. Accepts the values <code>horizontal</code>, <code>vertical</code>, and <code>both</code>. The default value is <code>both</code>.</Argument>
</Arguments>

## Examples

<Example caption="With no argument the element is centred on both axes, which is where a play button goes.">
```scss
.parent-element {
  position: relative;
  .element{
    position: absolute;
    @include center;
  }
}
```
```html
<style>
  body { background: #fafaf8; font: 14px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; color: #657167; }
  .parent-element { overflow: hidden; border-radius: 18px; background: url("/images/landscape.webp") center/cover; }
  .element { display: grid; place-items: center; width: 74px; height: 74px; margin: 0; border-radius: 999px; background: rgb(255 255 255 / 0.92); color: #668f80; font: 26px Inter, ui-sans-serif, system-ui, sans-serif; box-shadow: 0 10px 30px rgb(34 44 37 / 0.35); }
</style>
<div class="parent-element sandbox large example01">
  <h2 class="element">▶</h2>
</div>
```
</Example>

<Example caption="`horizontal` centres it on the horizontal axis alone, so the badge keeps the `top` the demo gives it.">
```scss
.parent-element {
  position: relative;
  .element{
    position: absolute;
    @include center(horizontal);
  }
}
```
```html
<style>
  body { background: #fafaf8; font: 14px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; color: #657167; }
  .parent-element { overflow: hidden; border-radius: 18px; background: linear-gradient(140deg, #2f3937, #668f80); }
  .element { margin: 0; top: 22px; padding: 9px 18px; border-radius: 999px; background: rgb(255 255 255 / 0.16); color: #f2f2eb; font: 600 13px Inter, ui-sans-serif, system-ui, sans-serif; letter-spacing: 0.08em; text-transform: uppercase; }
</style>
<div class="parent-element sandbox large example02">
  <h2 class="element">Now playing</h2>
</div>
```
</Example>

<Example caption="`vertical` does the other axis, and the label keeps its own `left`.">
```scss
.parent-element {
  position: relative;
  .element{
    position: absolute;
    @include center(vertical);
  }
}
```
```html
<style>
  body { background: #fafaf8; font: 14px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; color: #657167; }
  .parent-element { overflow: hidden; border-radius: 18px; background: #222c25; }
  .element { margin: 0; left: 24px; padding: 14px 18px; border-radius: 14px; background: #fafaf8; color: #668f80; font: 700 15px Inter, ui-sans-serif, system-ui, sans-serif; }
</style>
<div class="parent-element sandbox large example03">
  <h2 class="element">Pinned to the middle of the left edge</h2>
</div>
```
</Example>

<Example caption="`both` is the default written out, for a call that says what it does.">
```scss
.parent-element {
  position: relative;
  .element{
    position: absolute;
    @include center(both);
  }
}
```
```html
<style>
  body { background: #fafaf8; font: 14px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; color: #657167; }

  .element small { font: 600 12px Inter, ui-sans-serif, system-ui, sans-serif; color: #657167; letter-spacing: 0.08em; text-transform: uppercase; }

<div class="parent-element sandbox large example04">

</div>
```
</Example>
