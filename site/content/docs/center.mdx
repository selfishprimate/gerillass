# Center

<Member name="center">

The **Center** Sass mixin allows you to center elements (**those with a `position` value of either `absolute` or `fixed`**) on both the horizontal and vertical axes.
<Hint kind="info">

**Important:** You must set either `position: absolute` or `position: fixed` on the selected element to make this mixin work correctly. **The parent element you are centering within must have a `position` value other than `static`.**

</Hint>

<Hint kind="info">

**`transform` stays yours.** Since 4.0.0 the mixin writes the individual `translate` property instead, so a `transform` of your own, a rotation, a hover that scales, composes with the centring rather than replacing it. Until then a single `transform: scale(1.05)` on hover moved the element off centre: measured in Chrome 152, Firefox 156 and Safari 26.6.2, a 100 by 50 element centred in a 400 by 200 box sat 50px right and 25px below the middle in all three, and now stays where it is.

</Hint>

</Member>

## Arguments

<Arguments of="center" footnote="Pass the `both` value to center an element on both the horizontal and vertical axes, or pass nothing at all.">
  <Argument name="$axis" type="string">Sets the axis of the alignment. Accepts the values <code>horizontal</code>, <code>vertical</code>, and <code>both</code>. The default value is <code>both</code>.</Argument>
</Arguments>

## Examples

<Example caption="Simply call the mixin without passing any arguments **to center the selected element on both the horizontal and vertical axes**.">
```scss
.parent-element {
  position: relative;
  .element{
    position: absolute;
    @include center;
  }
}
```
```html
<style>
  body { background: #f1f5f9; font: 14px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; color: #0f172a; }
  .parent-element { overflow: hidden; border-radius: 18px; background: url("/images/landscape.webp") center/cover; }
  .element { display: grid; place-items: center; width: 74px; height: 74px; margin: 0; border-radius: 999px; background: rgb(255 255 255 / 0.92); color: #0f172a; font: 26px Inter, ui-sans-serif, system-ui, sans-serif; box-shadow: 0 10px 30px rgb(15 23 42 / 0.35); }
</style>
<div class="parent-element sandbox large example01">
  <h2 class="element">▶</h2>
</div>
```
</Example>
