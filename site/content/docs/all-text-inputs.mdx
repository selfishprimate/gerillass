# All Text Inputs

<Member name="all-text-inputs">

The **All Text Inputs** Sass mixin selects every form control a browser draws as a text field, so one rule styles them all: text, email, password, search, number, the date and time pickers, and `textarea`. It leaves out the controls that are not text fields, such as checkboxes, radios, colour pickers, range sliders, file pickers and buttons.

</Member>

## Arguments

<Arguments of="all-text-inputs" footnote="Call the mixin at the root of your stylesheet to style every text field on the page, or inside a selector to style only the ones within it.">
  <Argument name="$pseudo" type="string">A state to select the fields in. Accepts <code>hover</code>, <code>focus</code>, <code>focus-visible</code>, <code>active</code>, <code>invalid</code>, <code>user-invalid</code>, <code>required</code> and <code>disabled</code>. Leave it out for the plain state.</Argument>
</Arguments>

## What it matches

Measured in Chrome 152, Firefox 156 and Safari 26.6.2, by giving every kind of control the same text-field styles; `image` and `hidden` are left out by the selector and were not drawn:

| Styled | Left alone |
|---|---|
| `text`, `search`, `email`, `url`, `tel`, `password`, `number` | `checkbox`, `radio` |
| `date`, `datetime-local`, `month`, `week`, `time` | `color`, `range`, `file` |
| an `input` with no `type`, or a `type` the browser does not know, such as `datetime` | `submit`, `reset`, `button`, `image`, `hidden` |
| `textarea` | `select`, which is not a text field |

A browser draws an `input` whose `type` it does not recognise as a text field, and all three did, for the removed `datetime` and for a made-up `type="foo"`. Safari draws `month` and `week` as text too. So the mixin selects every `input` except the types that are not text fields, rather than listing the text ones.

<Hint kind="warning">

**Changed in Gerillass 4.0.0.** The list is now `input` less the types that are not text fields, so a colour picker is left alone, a type the browser does not know is styled like the text field it draws, and an element that merely carries a `type` attribute is not touched.

</Hint>

## Examples

<Example caption="A sign-up form. One rule styles the name, email and password fields, the date and the message, while the colour picker and the checkbox keep their own look. `select` is not a text field, so it gets its own rule; it is written beside the mixin here so the form matches.">
```scss
@include all-text-inputs {
  width: 100%;
  height: 38px;
  padding: 0 12px;
  border: 1px solid #dee0cd;
  border-radius: 6px;
  background: #fff;
  font: inherit;
  color: inherit;
}

select {
  width: 100%;
  height: 38px;
  padding: 0 8px;
  border: 1px solid #dee0cd;
  border-radius: 6px;
  background: #fff;
  font: inherit;
}
```
```html
<style>
  .form { display: grid; gap: 12px; max-width: 360px; font: 14px/1.4 Inter, ui-sans-serif, system-ui, sans-serif; color: #2f3937; }
  .field { display: grid; gap: 6px; }
  .field > span { font-weight: 500; }
  textarea { height: 76px; padding-top: 8px; resize: vertical; }
  .inline { display: flex; align-items: center; gap: 8px; }
</style>
<form class="form" onsubmit="return false">
  <label class="field"><span>Name</span><input placeholder="Ada Lovelace"></label>
  <label class="field"><span>Email</span><input type="email" placeholder="ada@example.com"></label>
  <label class="field"><span>Password</span><input type="password" value="secret"></label>
  <label class="field"><span>Start date</span><input type="date" value="2026-09-17"></label>
  <label class="field"><span>Plan</span><select><option>Pro</option><option>Team</option></select></label>
  <label class="field"><span>Message</span><textarea placeholder="Anything we should know?"></textarea></label>
  <label class="inline"><input type="color" value="#668f80"> Accent colour</label>
  <label class="inline"><input type="checkbox" checked> Send me product news</label>
</form>
```
</Example>

<Example caption="A focus ring on every text field, with the **Focus Ring** mixin inside this one. **Click into a field, or press the Tab key.** Form fields show `:focus-visible` on a click as well, so the ring appears either way.">
```scss
@include all-text-inputs {
  width: 100%;
  height: 38px;
  padding: 0 12px;
  border: 1px solid #dee0cd;
  border-radius: 6px;
  font: inherit;
  @include focus-ring(2px, 2px, #668f80);
}
```
```html
<style>
  .form { display: grid; gap: 12px; max-width: 360px; font: 14px/1.4 Inter, ui-sans-serif, system-ui, sans-serif; color: #2f3937; }
  .field { display: grid; gap: 6px; }
  .field > span { font-weight: 500; }
</style>
<form class="form" onsubmit="return false">
  <label class="field"><span>Search</span><input type="search" placeholder="Search the docs"></label>
  <label class="field"><span>Website</span><input type="url" placeholder="https://"></label>
</form>
```
</Example>

<Example caption="An error style that waits for the user, with `user-invalid`. Nothing is marked while the form is untouched. **Type something that is not an email address, then click outside the field.**">
```scss
@include all-text-inputs {
  width: 100%;
  height: 38px;
  padding: 0 12px;
  border: 1px solid #dee0cd;
  border-radius: 6px;
  font: inherit;
}

@include all-text-inputs(user-invalid) {
  border-color: #db504a;
  background: #fafaf8;
}
```
```html
<style>
  .form { display: grid; gap: 12px; max-width: 360px; font: 14px/1.4 Inter, ui-sans-serif, system-ui, sans-serif; color: #2f3937; }
  .field { display: grid; gap: 6px; }
  .field > span { font-weight: 500; }
</style>
<form class="form" onsubmit="return false">
  <label class="field"><span>Email</span><input type="email" required placeholder="ada@example.com"></label>
</form>
```
</Example>

<Hint kind="warning">

**Prefer `user-invalid` to `invalid` for error styles.** An empty required field matches `:invalid` on page load, so the error shows on a form nobody has touched; `:user-invalid` waits until the field has been filled in and left, or the form submitted.

</Hint>

<Example caption="Disabled fields, dimmed so they read as unavailable, with a cursor that says so.">
```scss
@include all-text-inputs(disabled) {
  background: #fafaf8;
  color: #657167;
  cursor: not-allowed;
}
```
```html
<style>
  .form { display: grid; gap: 12px; max-width: 360px; font: 14px/1.4 Inter, ui-sans-serif, system-ui, sans-serif; color: #2f3937; }
  .field { display: grid; gap: 6px; }
  .field > span { font-weight: 500; }
  .field input { width: 100%; height: 38px; padding: 0 12px; border: 1px solid #dee0cd; border-radius: 6px; font: inherit; }
</style>
<form class="form" onsubmit="return false">
  <label class="field"><span>Account ID</span><input value="acc_48213" disabled></label>
  <label class="field"><span>Display name</span><input value="Ada"></label>
</form>
```
</Example>

<Example caption="Inside a selector, only the fields within it are styled. The search bar's field is borderless to sit inside its pill, and the field below, outside the bar, is untouched.">
```scss
.search-bar {
  @include all-text-inputs {
    flex: 1;
    min-width: 0;
    border: 0;
    background: transparent;
    font: inherit;
    outline: none;
  }
}
```
```html
<style>
  .search-bar { display: flex; align-items: center; gap: 8px; max-width: 360px; height: 40px; padding: 0 14px; border-radius: 999px; background: #fafaf8; font: 14px/1 Inter, ui-sans-serif, system-ui, sans-serif; color: #2f3937; }
  .below { margin-top: 12px; }
</style>
<div class="search-bar"><span aria-hidden="true">&#128269;</span><input type="search" placeholder="Search"></div>
<input class="below" type="text" placeholder="Outside the bar, so untouched">
```
</Example>
