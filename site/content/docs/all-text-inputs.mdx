# All Text Inputs

<Member name="all-text-inputs">

The **All Text Inputs** Sass mixin helps you target all the text-based HTML input elements in the DOM, so you can easily apply your style rules.

</Member>

## Arguments

<Arguments of="all-text-inputs" footnote="You can call the mixin at the root level of your stylesheet to target all the text-based input elements in the DOM, or call it inside a selector to target only the elements that are children of that selector.">
  <Argument name="$pseudo" type="string">Sets the pseudo-class selector for the selected text-based input elements. Accepts the values <code>hover</code>, <code>focus</code>, <code>active</code>, <code>invalid</code>, <code>required</code>, and <code>disabled</code>.</Argument>
</Arguments>

## Examples

<Example caption="Simply call the mixin at the root level of your stylesheet **to target all the text-based input elements**.">
```scss
@include all-text-inputs {
  background-color: #e6e6e6;
}
```
```html
<input type="text" placeholder="A text input" style="width: 100%; margin-bottom: 8px" />
<input type="email" placeholder="An email input" style="width: 100%; margin-bottom: 8px" />
<textarea placeholder="And a textarea" rows="2" style="width: 100%"></textarea>
```
</Example>

<Example caption="Let's target all the text-based HTML inputs with the **:hover** pseudo-class selector applied.">
```scss
@include all-text-inputs(hover) {
  background-color: orange;
}
```
```html
<input type="text" placeholder="A text input" style="width: 100%; margin-bottom: 8px" />
<input type="email" placeholder="An email input" style="width: 100%; margin-bottom: 8px" />
<textarea placeholder="And a textarea" rows="2" style="width: 100%"></textarea>
```
</Example>

<Example caption="Let's target all the text-based HTML inputs with the **:focus** pseudo-class selector applied.">
```scss
@include all-text-inputs(focus) {
  background-color: green;
}
```
```html
<input type="text" placeholder="A text input" style="width: 100%; margin-bottom: 8px" />
<input type="email" placeholder="An email input" style="width: 100%; margin-bottom: 8px" />
<textarea placeholder="And a textarea" rows="2" style="width: 100%"></textarea>
```
</Example>

<Example caption="Now let's target all the text-based HTML inputs with the **:active** pseudo-class selector applied.">
```scss
.element {
  @include all-text-inputs(active) {
    background-color: green;
    color: white;
  };
}
```
```html
<div class="element">
<input type="text" placeholder="A text input" style="width: 100%; margin-bottom: 8px" />
<input type="email" placeholder="An email input" style="width: 100%; margin-bottom: 8px" />
<textarea placeholder="And a textarea" rows="2" style="width: 100%"></textarea>
</div>
```
</Example>

<Example caption="Now let's target all the text-based HTML inputs with the **:invalid** pseudo-class selector applied.">
```scss
.element {
  @include all-text-inputs(invalid) {
    background-color: red;
    color: white;
  };
}
```
```html
<div class="element">
  <input type="email" value="not-an-email-address" style="width: 100%; margin-bottom: 8px" />
  <input type="email" value="valid@example.com" style="width: 100%" />
</div>
```
</Example>

<Example caption="Now let's try it with the **:required** pseudo-class selector applied.">
```scss
.element {
  @include all-text-inputs(required) {
    background-color: orange;
    color: white;
  };
}
```
```html
<div class="element">
  <input type="text" placeholder="Required" required style="width: 100%; margin-bottom: 8px" />
  <input type="text" placeholder="Optional" style="width: 100%" />
</div>
```
</Example>

<Example caption="Now let's try it with the **:disabled** pseudo-class selector applied.">
```scss
.element {
  @include all-text-inputs(disabled) {
    background-color: gray;
    color: black;
  };
}
```
```html
<div class="element">
  <input type="text" value="Disabled" disabled style="width: 100%; margin-bottom: 8px" />
  <input type="text" value="Enabled" style="width: 100%" />
</div>
```
</Example>

<Example caption="Call the mixin inside a selector to target only the text-based input elements inside that selector.">
```scss
.containing-element {
  @include all-text-inputs {
    background-color: green;
  }
}
```
```html
<div class="containing-element">
<input type="text" placeholder="A text input" style="width: 100%; margin-bottom: 8px" />
<input type="email" placeholder="An email input" style="width: 100%; margin-bottom: 8px" />
<textarea placeholder="And a textarea" rows="2" style="width: 100%"></textarea>
</div>
<input type="text" placeholder="Outside it, so untouched" style="width: 100%; margin-top: 8px" />
```
</Example>
