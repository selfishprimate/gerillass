# Sizer

<Member name="sizer">

The **Sizer Sass mixin** helps you size elements with one statement (or two). Size elements or create squares and rectangles very easily.

</Member>

## Arguments

<Arguments of="sizer">
  <Argument name="$width" type="number (with unit),<br/>string">Sets the width of the selected elements. Accepts a length or a percentage, <code>auto</code>, <code>min-content</code>, <code>max-content</code>, <code>fit-content</code>, <code>stretch</code>, a CSS-wide keyword, <code>var()</code>, a maths function such as <code>calc()</code>, <code>anchor-size()</code> and <code>calc-size()</code>.</Argument>
  <Argument name="$height" type="number (with unit),<br/>string">Sets the height of the selected elements. The default value is the <code>$width</code> value. Accepts the same values as <code>$width</code>.</Argument>
</Arguments>

## Examples

<Example caption="One value is the width and the height together, which is the square a logo tile wants.">
```scss
.element{
  @include sizer(200px);
}
```
```html
<style>
  body { background: #fafaf8; font: 14px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; color: #668f80; }

</style>
<div class="element">G</div>
```
</Example>

<Example caption="Two values are the width and the height, in that order.">
```scss
.element{
  @include sizer(500px, 100px);
}
```

<Example caption="A keyword works where a length does, so `auto` leaves the height to the content.">
```scss
.element{
  @include sizer(400px, auto);
}
```
```html
<style>
  body { background: #fafaf8; font: 14px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; color: #668f80; }
  .element { padding: 18px 20px; border-radius: 16px; background: #fff; box-shadow: 0 6px 20px rgb(34 44 37 / 0.08); color: #2f3937; }
</style>
<div class="element">A width the layout decides and a height the content decides, which is what <code>auto</code> is for: the card is exactly as tall as this sentence makes it.</div>
```
</Example>

## What it refuses

A width or height the browser drops stops the build. Measured in Chrome 152, that is a word that is not a sizing keyword, a unitless number other than `0`, a unit that is not a length such as `deg`, a negative length, a length in quotes, and two values where one is meant. Until 2.3.1 all of these compiled, and the browser dropped the declaration without a word.

```scss
.element {
  @include sizer(400px, huge);
}
```
```text
Error: `huge` is not a valid $height for `sizer`: it is not a length or one of: min-content, max-content, fit-content, stretch, -webkit-fill-available, -moz-available, auto. A browser drops the declaration.
```
