# Linear Gradient

<Member name="linear-gradient">

The **Linear Gradient Sass mixin** helps you generate colorful CSS gradients and combine them with image and text elements. This way, you can create beautiful page components.

The one-line method makes it very easy to use. To generate a linear gradient, you must pass a value for the `$direction` angle and at least two color values. You can also add color stop points (the starting and ending positions of the colors).

<Hint kind="info">

Color stop points can be defined with `length` or `percentage` units.

</Hint>

</Member>

## Arguments

<Arguments of="linear-gradient" footnote="**Important:** When you use color stop points together with the color values, each group of values must be wrapped in parentheses and separated by a space. See the <a href='#examples'>examples</a> for more.">
  <Argument name="$direction" type="string, number">Sets the direction of the gradient line. Accepts the string values <code>top</code>, <code>top-right</code>, <code>right</code>, <code>bottom-right</code>, <code>bottom</code>, <code>bottom-left</code>, <code>left</code>, and <code>top-left</code>. You can also pass a custom value as a number followed by a <code>deg</code> unit.</Argument>
  <Argument name="$colors" type="list">Accepts a list of colors, with or without color stop points. You can pass as many color values as you want. A stop is a colour followed by up to two positions, and a position on its own between two colours is a hint, such as <code>(red, 30%, blue)</code>. <code>var()</code> works for a stop or the whole list.</Argument>
</Arguments>

## Examples

<Example caption="Simply call the mixin inside a selector and pass values for both the `$direction` and `$colors` arguments.">
```scss
.element{
  @include linear-gradient(right, #43c6ac #191654);
}
```
```html
<div class="element sandbox large"></div>
```
</Example>

<Example caption="Let's try it with named arguments and add one more color stop.">
```scss
.element{
  @include linear-gradient(
    $direction: right,
    $colors: #43c6ac #191654 #963d91
  );
}
```
```html
<div class="element sandbox large"></div>
```
</Example>

<Example caption="We can use color stop positioning to adjust the transition between the colors.">
```scss
.element{
  @include linear-gradient(
    $direction: right,
    $colors: (#1a2a6c 0 10%) (#b21f1f 30% 60%) (#fdbb2d 90% 100%)
  );
}
```
```html
<div class="element sandbox large"></div>
```
</Example>

<Example caption="Let's sharpen the transition between the color stops.">
```scss
.element{
  @include linear-gradient(
    $direction: right,
    $colors: (#1a2a6c 25%) (#b21f1f 25% 50%) (#fdbb2d 50% 75%) (orange 75% 100%)
  );
}
```
```html
<div class="element sandbox large"></div>
```
</Example>

## What it refuses

A colour stop the browser drops stops the build, because the browser drops the whole gradient with it. Measured in Chrome 152: a word that is not a colour, a quoted colour, a CSS-wide keyword, a position first or last, two positions in a row, a stop with three positions, and a position that is not a length or a percentage. Until 2.3.1 each of those compiled.

```scss
.element {
  @include linear-gradient("top", (red, 10%));
}
```
```text
Error: `red, 10%` is not a valid $colors for `linear-gradient`: it ends with the position `10%`; a position on its own goes between two colours. A browser drops the whole gradient.
```
