# Text Gradient

<Member name="text-gradient">

The **Text Gradient** Sass mixin (also known as **CSS Gradient Text**) helps you add a gradient overlay to a text element. It provides a one-line method to set the direction of the gradient line, the color values, and the color stop positions very easily. 

<Hint kind="info">

A color stop position can be defined with `length` or `percentage` units.

</Hint>

</Member>

<Hint kind="warning">

**Changed in Gerillass 3.0.0:** the colours come first, and the direction is a named argument. `text-gradient("top", (red, blue))` is now `text-gradient((red, blue), $direction: top)`. A call in the old order stops the build with the new form written out. The mixin also takes every argument the [gradient](/docs/gradient) mixin takes, so text can carry a radial, conic or repeating gradient and blend in a colour space.

</Hint>

## Arguments

<Arguments of="text-gradient">
  <Argument name="$colors" type="list">The colour stops, in the forms the `gradient` mixin takes. Each stop is a colour with up to two positions, wrapped in parentheses when it has positions.</Argument>
  <Argument name="$type" type="string">`linear`, the default, `radial` or `conic`.</Argument>
  <Argument name="$direction" type="string, number">Linear only. A name such as `top` or `bottom-left`, an angle in any unit, `"to left top"`, or `var()`.</Argument>
  <Argument name="$shape" type="string">Radial only. `circle` or `ellipse`, with an optional size.</Argument>
  <Argument name="$position" type="string">Radial or conic. A name such as `center`, or `"at 30% 40%"`.</Argument>
  <Argument name="$from" type="number">Conic only. The angle the gradient starts at.</Argument>
  <Argument name="$in" type="string">A colour space such as `oklab`.</Argument>
  <Argument name="$repeating" type="boolean">`true` for a repeating gradient.</Argument>
</Arguments>

## Examples

<Example caption="Pass the colours and a direction. As many colours as you like.">
```scss
.element{
  @include text-gradient(orange red purple blue green, $direction: right);
}
```
```html
<h2 class="element sandbox text">Text Gradient is Awesome!</h2>
```
</Example>

<Example caption="With named arguments the call reads the same in any order.">
```scss
.element{
  @include text-gradient(
    $colors: red orange,
    $direction: top-left
  );
}
```
```html
<h2 class="element sandbox text">Text Gradient is Awesome!</h2>
```
</Example>

<Example caption="Colour stop positions make the colours meet at a hard edge.">
```scss
.element{
  @include text-gradient((red 50%) (orange 50%), $direction: bottom);
}
```
```html
<h2 class="element sandbox text">Text Gradient is Awesome!</h2>
```
</Example>

<Example caption="A colour can take a start and an end position.">
```scss
.element{
  @include text-gradient(
    (green 0 40%) (blue 40% 60%) (purple 60% 100%),
    $direction: top
  );
}
```
```html
<h2 class="element sandbox text">Text Gradient is Awesome!</h2>
```
</Example>

<Example caption="The transitions do not have to be sharp.">
```scss
.element{
  @include text-gradient((red 30%) (orange 60%) (brown 80%), $direction: bottom);
}
```
```html
<h2 class="element sandbox text">Text Gradient is Awesome!</h2>
```
</Example>

<Example caption="Blend in oklab for an even transition between two colours.">
```scss
.element{
  @include text-gradient(#2563eb #db2777, $direction: right, $in: oklab);
}
```
```html
<h2 class="element sandbox text">Text Gradient is Awesome!</h2>
```
</Example>

<Example caption="A conic gradient sweeps a rainbow round the middle of the words.">
```scss
.element{
  @include text-gradient(#ef4444 #f59e0b #22c55e #3b82f6 #a855f7 #ef4444, conic);
}
```
```html
<h2 class="element sandbox text">Text Gradient is Awesome!</h2>
```
</Example>

<Example caption="A repeating gradient stripes the letters, a retro poster look.">
```scss
.element{
  @include text-gradient(
    (#db2777 0 6px) (#f59e0b 6px 12px),
    $direction: 45deg,
    $repeating: true
  );
}
```
```html
<h2 class="element sandbox text">Text Gradient is Awesome!</h2>
```
</Example>

## What it refuses

A call in the order used before 3.0.0 stops the build and shows the new form.

```scss
.element {
  @include text-gradient("top", (red, blue));
}
```
```text
Error: `text-gradient` takes the colours first since 3.0.0. Write `text-gradient((red, blue), $direction: "top")`.
```

A colour stop the browser drops stops the build too. Here it matters twice: the browser drops the gradient, and the mixin has already made the text transparent, so the text disappears.

```scss
.element {
  @include text-gradient((huge, blue));
}
```
```text
Error: `huge, blue` is not a valid $colors for `text-gradient`: `huge` is not a colour stop: it is not a colour. A browser drops the whole gradient.
```
