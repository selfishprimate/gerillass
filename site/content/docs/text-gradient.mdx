# Text Gradient

<Member name="text-gradient">

The **Text Gradient** Sass mixin (also known as **CSS Gradient Text**) helps you add a gradient overlay to a text element. It provides a one-line method to set the direction of the gradient line, the color values, and the color stop positions very easily. 

<Hint kind="info">

A color stop position can be defined with `length` or `percentage` units.

</Hint>

</Member>

<Hint kind="warning">

**Changed in Gerillass 3.0.0:** the colours come first, and the direction is a named argument. `text-gradient("top", (red, blue))` is now `text-gradient((red, blue), $direction: top)`. A call in the old order stops the build with the new form written out. The mixin also takes every argument the [gradient](/docs/gradient) mixin takes, so text can carry a radial, conic or repeating gradient and blend in a colour space.

</Hint>

## Arguments

<Arguments of="text-gradient">
  <Argument name="$colors" type="list">The colour stops, in the forms the `gradient` mixin takes. Each stop is a colour with up to two positions, wrapped in parentheses when it has positions.</Argument>
  <Argument name="$type" type="string">`linear`, the default, `radial` or `conic`.</Argument>
  <Argument name="$direction" type="string, number">Linear only. A name such as `top` or `bottom-left`, an angle in any unit, `"to left top"`, or `var()`.</Argument>
  <Argument name="$shape" type="string">Radial only. `circle` or `ellipse`, with an optional size.</Argument>
  <Argument name="$position" type="string">Radial or conic. A name such as `center`, or `"at 30% 40%"`.</Argument>
  <Argument name="$from" type="number">Conic only. The angle the gradient starts at.</Argument>
  <Argument name="$in" type="string">A colour space such as `oklab`.</Argument>
  <Argument name="$repeating" type="boolean">`true` for a repeating gradient.</Argument>
</Arguments>

## Examples

### The basics

<Example caption="Pass the colours and a direction. As many colours as you like.">
```scss
.element{
  @include text-gradient(#ed6a5a #f7ec59 #bdc488 #5bc0bb #668f80, $direction: right);
}
```
```html
<h2 class="element sandbox text">Text Gradient is Awesome!</h2>
```
</Example>

<Example caption="With named arguments the call reads the same in any order.">
```scss
.element{
  @include text-gradient(
    $colors: red orange,
    $direction: top-left
  );
}
```
```html
<h2 class="element sandbox text">Text Gradient is Awesome!</h2>
```
</Example>

<Example caption="Colour stop positions make the colours meet at a hard edge.">
```scss
.element{
  @include text-gradient((#668f80 50%) (#5bc0bb 50%), $direction: bottom);
}
```
```html
<h2 class="element sandbox text">Text Gradient is Awesome!</h2>
```
</Example>

<Example caption="A colour can take a start and an end position.">
```scss
.element{
  @include text-gradient(
    (green 0 40%) (blue 40% 60%) (purple 60% 100%),
    $direction: top
  );
}
```
```html
<h2 class="element sandbox text">Text Gradient is Awesome!</h2>
```
</Example>

<Example caption="The transitions do not have to be sharp.">
```scss
.element{
  @include text-gradient((#ed6a5a 30%) (#f7ec59 60%) (#bdc488 80%), $direction: bottom);
}
```
```html
<h2 class="element sandbox text">Text Gradient is Awesome!</h2>
```
</Example>

<Example caption="Blend in oklab for an even transition between two colours.">
```scss
.element{
  @include text-gradient(#668f80 #db504a, $direction: right, $in: oklab);
}
```
```html
<h2 class="element sandbox text">Text Gradient is Awesome!</h2>
```
</Example>

<Example caption="A conic gradient sweeps a rainbow round the middle of the words.">
```scss
.element{
  @include text-gradient(#ed6a5a #69995d #2f3937 #668f80 #5bc0bb #ed6a5a, conic);
}
```
```html
<h2 class="element sandbox text">Text Gradient is Awesome!</h2>
```
</Example>

<Example caption="A repeating gradient stripes the letters, a retro poster look.">
```scss
.element{
  @include text-gradient(
    (#db504a 0 6px) (#69995d 6px 12px),
    $direction: 45deg,
    $repeating: true
  );
}
```
```html
<h2 class="element sandbox text">Text Gradient is Awesome!</h2>
```
</Example>

### In real interfaces

Each of these is the mixin alone. The only other declaration is the font, so the letters are big enough to show the gradient. They are spans rather than blocks: the gradient paints the element's box, and a block is as wide as the page, so a diagonal, radial or conic gradient would spread far past the word.

<Example caption="Highlight one word of a hero headline. The gradient sits on a span, so the rest of the sentence keeps its colour.">
```scss
.headline{
  font: 800 44px/1.1 system-ui, sans-serif;

  span{
    @include text-gradient(#5bc0bb #ed6a5a, $direction: right, $in: oklab);
  }
}
```
```html
<h1 class="headline">Design at the <span>speed of thought</span></h1>
```
</Example>

<Example caption="A price on a pricing card, blended in oklch so the colours stay vivid across the digits.">
```scss
.price{
  font: 800 72px/1 system-ui, sans-serif;
  @include text-gradient(#668f80 #69995d, $direction: 135deg, $in: oklch);
}
```
```html
<span class="price">$29/mo</span>
```
</Example>

<Example caption="A metallic label for a premium tier. Stops crowded at the middle give the letters the bright band that metal has.">
```scss
.premium{
  font: 900 48px/1 system-ui, sans-serif;
  @include text-gradient(
    (#2f3937 0%) (#69995d 45%) (#f2f2eb 50%) (#bdc488 55%) (#2f3937 100%),
    $direction: top
  );
}
```
```html
<span class="premium">PREMIUM</span>
```
</Example>

<Example caption="A wordmark split in two colours by a hard diagonal, from two stops that meet at 50%.">
```scss
.wordmark{
  font: 900 64px/1 system-ui, sans-serif;
  @include text-gradient((#222c25 50%) (#69995d 50%), $direction: 135deg);
}
```
```html
<span class="wordmark">SPLIT</span>
```
</Example>

<Example caption="A glowing title: a radial gradient is brightest in the middle of the word and cools towards the ends.">
```scss
.glow{
  font: 900 56px/1 system-ui, sans-serif;
  @include text-gradient(#5bc0bb #668f80 #2f3937, radial, $shape: ellipse, $position: center);
}
```
```html
<span class="glow">LAUNCH DAY</span>
```
</Example>

<Example caption="A holographic label. A conic gradient blended the long way round the hue circle gives the letters every colour at once.">
```scss
.holo{
  font: 900 64px/1 system-ui, sans-serif;
  @include text-gradient(#5bc0bb #5bc0bb, conic, $from: 45deg, $in: oklch longer hue);
}
```
```html
<span class="holo">HOLO</span>
```
</Example>

## What it refuses

A call in the order used before 3.0.0 stops the build and shows the new form.

```scss
.element {
  @include text-gradient("top", (red, blue));
}
```
```text
Error: `text-gradient` takes the colours first since 3.0.0. Write `text-gradient((red, blue), $direction: "top")`.
```

A colour stop the browser drops stops the build too. Here it matters twice: the browser drops the gradient, and the mixin has already made the text transparent, so the text disappears.

```scss
.element {
  @include text-gradient((huge, blue));
}
```
```text
Error: `huge, blue` is not a valid $colors for `text-gradient`: `huge` is not a colour stop: it is not a colour. A browser drops the whole gradient.
```

<Hint kind="info">

**Forced colours are handled since 4.0.0.** The letters have no colour of their own here: the gradient is the only thing painting them. In that mode the browser forces `background-image: none` and forces `color`, but `-webkit-text-fill-color` is not a forced property, so the transparent fill survived and the heading disappeared. The mixin now writes a `@media (forced-colors: active)` block that gives both back: measured with forced colours on, the computed fill colour was `rgba(0, 0, 0, 0)` before and is black now, in Chrome 152 and Firefox 156. Safari has no way to turn forced colours on from automation, so it was not measured there.

</Hint>
