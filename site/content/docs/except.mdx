# Except

<Member name="except">

The **Except** Sass mixin helps you apply style changes to every element in a list except the ones you choose.
<Hint kind="info">

You can pass a **string** value to target elements by their `id`, `class`, or `pseudo-class` selector. Or you can pass a **number** (or **multiple numbers** separated by commas) to target items by their index position in the list.

</Hint>

</Member>

## Arguments

<Arguments of="except" footnote="**Important:** Passing multiple arguments only works with numeric values, and the values must be separated by commas.">
  <Argument name="$params…" type="string">The pseudo-class, class, or id selector. Accepts <code>first</code>, <code>last</code>, <code>odd</code>, <code>even</code>, and class or id selectors.</Argument>
  <Argument name="$params…" type="number">The index number of the element in the list, a whole number counted from 1, or from the end when negative. You can also make multiple selections. A number with a unit, a fraction and <code>0</code> are refused.</Argument>
  <Argument name="$of" type="string (quoted)">The selector to count by, such as <code>".card"</code>. Without it the count is <code>:nth-of-type</code>, which counts siblings of the same tag; with it the mixin writes <code>:not(:nth-child(… of .card))</code>, which counts only those.</Argument>
</Arguments>

## Examples

Let's say you have a list of items wrapped in a container, just like the example below. Now you want to apply some style changes to all of them, **except** for one or more.

```html
<div class="list-wrapper">
  <div class="list-item">01</div>
  <div class="list-item">02</div>
  <div class="list-item">03</div>
  <div class="list-item">04</div>
  <div class="list-item">05</div>
  <div class="list-item">06</div>
</div>
```

<Example caption="Let's exclude the **first** one!">

## What it refuses

A position has to be a whole number. Until 2.3.1 anything numeric went into the selector as it was, and measured in Chrome 152, `:not(:nth-of-type(1.5))` is an invalid selector, so the browser drops the whole rule and nothing is styled.

```scss
.list-item {
  @include except(1.5) {
    color: red;
  }
}
```
```text
Error: `1.5` is not a valid position for `except`: a position is a whole number, and `:nth-of-type(1.5)` is an invalid selector, so the browser would drop the rule. Pass a number such as `2`, or `-2` to count from the end.
```

A multiple of `n` is a position too: `except(3n)` writes `:not(:nth-of-type(3n))` and leaves out every third element. An offset cannot be added, because Sass does the arithmetic first: `except(2n+1)` arrives as `3n`. For odd or even elements, pass `odd` or `even`.

`0` is valid CSS but excludes nothing, because positions count from 1.

```scss
.list-item {
  @include except(0) {
    color: red;
  }
}
```
```text
Error: `0` is not a valid position for `except`: positions count from 1, so `:not(:nth-of-type(0))` excludes nothing. Pass `1` for the first, or `-1` for the last.
```

## Counting by something other than the tag

`:nth-of-type` counts an element's siblings **of the same tag**, not the things
being counted, so one stray element moves every number. In this grid the first
`div` is the note, not a card:

```html
<div class="grid">
  <div class="note">On sale this week</div>
  <div class="card">A</div>
  <div class="card">B</div>
  <div class="card">C</div>
</div>
```

```scss
.card {
  @include except(1) {
    opacity: 0.5;
  }
}
```

That fades **every** card, because no card is the first `div`. Measured in
Chrome 152, Firefox 156 and Safari 26.6.2, all three the same. `$of` says what
to count:

<Example caption="Everything but the first card, counted by the cards. The note is not counted and is not faded." listing="<div class=&quot;grid&quot;>
&#32;&#32;<div class=&quot;note&quot;>On sale this week</div>
&#32;&#32;<div class=&quot;card&quot;>A</div>
&#32;&#32;<div class=&quot;card&quot;>B</div>
&#32;&#32;<div class=&quot;card&quot;>C</div>
</div>">
```scss
.card {
  @include except(1, $of: ".card") {
    opacity: 0.45;
  }
}
```
```html
<style>

  .card { flex: 1; padding: 12px; border-radius: 8px; background: #0f766e; color: #ecfeff; text-align: center; font-weight: 700; }
</style>
<div class="grid">
  <div class="note">On sale this week</div>
  <div class="card">A</div>
  <div class="card">B</div>
  <div class="card">C</div>
</div>
```
</Example>

<Hint kind="info">

**`$of` counts, it does not narrow.** `except(".featured")` is a different thing: it excludes the elements carrying that selector rather than counting anything, so passing both raises with a message saying which one you want. `:nth-child(… of S)` is in Chrome 111, Firefox 113 and Safari 9, and `CSS.supports` answers true in all three.

</Hint>
