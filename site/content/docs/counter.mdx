# Counter

<Member name="counter">

The **Counter** Sass mixin numbers the children of the element you include it in. It creates a CSS counter on that element, advances it on each child, and writes the number into the child's `::before`, with optional text around it and your own styles in a block. The markup needs no classes.

</Member>

<Hint kind="warning">

**Changed in Gerillass 4.0.0.** The mixin used to read three classes, `counter-start`, `counter-continue` and `counter-item`. It now numbers the direct children of the element it is included in, and `$name`, `$continue`, `$start` and `$items` do what the classes did and more. A list carries on from another by naming it, `$continue: tips`, so several split lists on one page keep their own counts. The numbers also survive children that are containers, which showed 1 on every item before. See the migration guide.

</Hint>

## Arguments

<Arguments of="counter" footnote="The counter style and the text around the number are positional, as before. The rest are named. See the [examples](#examples) for each.">
  <Argument name="$counter" type="string">The counter style, such as <code>decimal-leading-zero</code>, <code>upper-roman</code> or <code>lower-alpha</code>. The default is <code>decimal</code>.</Argument>
  <Argument name="$counter-before" type="string, function">Text before the number. A <code>var()</code>, <code>attr()</code>, <code>counter()</code> or <code>counters()</code> is written as it is.</Argument>
  <Argument name="$counter-after" type="string, function">Text after the number. With only one text and no style it goes after the number.</Argument>
  <Argument name="$continue" type="string">The <code>$name</code> of an earlier list to carry on from, instead of starting at 1.</Argument>
  <Argument name="$start" type="number, function">The first child's number, such as <code>4</code>, or a <code>var()</code> the markup sets.</Argument>
  <Argument name="$name" type="string">The counter's name, one word. Give one to a list that another list continues, and to a list inside another list. Lists with no name share one counter.</Argument>
  <Argument name="$items" type="string">A selector for the children to number, such as <code>"li"</code> or <code>".step"</code>. The default is every direct child.</Argument>
</Arguments>

## Skipping an item

<Hint kind="warning">

**Containers, measured in Chrome 152, Firefox 156 and Safari 26.6.2.** A list that is a container numbers its items in all three. Two things do not work. `$continue` cannot carry a count into or out of a list that is a container, since containment keeps the count inside it; pass `$start` with the first number instead. And in Safari a number reads 0 when **the numbered item itself** is a container, while Chrome and Firefox show the right number; put `container-type` on an element inside the item instead, which works in all three.

</Hint>

<Hint kind="info">

**This mixin and CSS's `counter()`.** The mixin writes `counter-reset`, `counter-increment` and `content: counter(...)` for you. To show the same count somewhere else, such as a total in a heading, give it a `$name` and read it with `counter()` in your own CSS or through the [Before](/docs/before) mixin.

</Hint>
