# Counter

<Member name="counter">

The **Counter** Sass mixin allows you to present your content in a **listicle** format. 
<Hint kind="info">

**Important:** The mixin must be applied to the parent element that has the `counter-start` class on it, so that all the children with the `counter-item` class are affected.

</Hint>

<Hint kind="warning">

**Tip:** **If you want to continue a list** that is interrupted by other content, simply give the containing element the **'counter-continue'** class instead of **'counter-start'**.

</Hint>

The markup should look like the example below:
```html
<div class="listicle-wrapper counter-start">
  <div class="item counter-item">LISTICLE ITEM 01</div>
  <div class="item counter-item">LISTICLE ITEM 02</div>
  <div class="item counter-item">LISTICLE ITEM 03</div>
</div>
```

</Member>

## Arguments

<Arguments of="counter" footnote="See the [examples](#examples) to learn how these arguments behave.">
  <Argument name="$counter" type="string">Sets the style of the counter. The default value is <code>decimal</code>. Check out the [links](#related-links) at the end of the article to learn more about counter styles.</Argument>
  <Argument name="$counter-before" type="string">Adds a string before the counter.</Argument>
  <Argument name="$counter-after" type="string">Adds a string after the counter.</Argument>
</Arguments>

## Examples

Suppose you have markup like the one below and you want to present it in a listicle format. (The same markup is used for all the examples.)

```html
<div class="listicle-wrapper counter-start">
  <div class="item counter-item">As an alternative theory, (and because Latin scholars do this sort of thing) someone.</div>
  <div class="item counter-item">The purpose of lorem ipsum is to create a natural looking block of text.</div>
  <div class="item counter-item">More difficult to find examples of lorem ipsum in use before Letraset made it popular.</div>
  <div class="item counter-item">McClintock says he remembers coming across the lorem ipsum passage in a book of old metal.</div>
  <div class="item counter-item">It's difficult to find examples of lorem ipsum in use before Letraset made it.</div>
</div>
```

<Example caption="Simply call the mixin inside the parent element's selector without passing any arguments.">
```scss
.listicle-wrapper {
  @include counter;
}
```

<Hint kind="info">

**Important:** Values that you pass outside the predefined **counter style** values are placed either **before** or **after** the counter. If you pass **only one** value, **it is placed after the counter**. If you pass **two values**, the **first one** is placed **before** the counter and the **second one after** it.

</Hint>
