# Gradient

<Member name="gradient">

The **Gradient Sass mixin** writes a linear, radial or conic gradient as `background-image`. The colours come first, so a plain two-colour gradient is one short call, and everything else has a default: the type is linear unless you say otherwise.

It sits beside `linear-gradient` and `radial-gradient` while the three are compared. Unlike them it writes `background-image` rather than the `background` shorthand, which resets a `background-color` set before it.

<Hint kind="info">

`$in` sets the colour space the gradient blends in. Blue to yellow goes grey in the middle in the browser's default sRGB, and stays clear `in oklab`. The mixin writes the gradient once without the space first, so a browser that does not know `in` still draws one.

</Hint>

</Member>

## Arguments

<Arguments of="gradient">
  <Argument name="$colors" type="list">The colour stops. A stop is a colour followed by up to two positions, and a position on its own between two colours is a hint. In a conic gradient the positions are angles or percentages. A single colour warns, since browsers before Chrome 135, Firefox 136 and Safari 18.4 drop it.</Argument>
  <Argument name="$type" type="string">`linear`, the default, `radial` or `conic`.</Argument>
  <Argument name="$direction" type="string, number">Linear only. A name such as `top` or `bottom-left`, an angle in any unit such as `0.25turn`, `"to left top"`, or `var()`.</Argument>
  <Argument name="$shape" type="string">Radial only. `circle` or `ellipse`, with an optional size such as `"circle 10px"`.</Argument>
  <Argument name="$position" type="string">Radial or conic. A name such as `center` or `top-left`, or `"at 30% 40%"`.</Argument>
  <Argument name="$from" type="number">Conic only. The angle the gradient starts at.</Argument>
  <Argument name="$in" type="string">A colour space such as `oklab`, or a polar one with a hue method such as `"oklch longer hue"`.</Argument>
  <Argument name="$repeating" type="boolean">`true` for a repeating gradient.</Argument>
</Arguments>

## Examples

### Linear gradients

Everything `linear-gradient` did, with the colours first and the direction named.

<Example caption="Pass the colours and a direction. With no direction the gradient runs top to bottom, the CSS default.">
```scss
.element{
  @include gradient(#43c6ac #191654, $direction: right);
}
```
```html
<div class="element sandbox large"></div>
```
</Example>

<Example caption="Add as many colours as you like.">
```scss
.element{
  @include gradient(#43c6ac #191654 #963d91, $direction: right);
}
```
```html
<div class="element sandbox large"></div>
```
</Example>

<Example caption="Colour stop positions set where each colour starts and ends, so the transitions only happen in the gaps.">
```scss
.element{
  @include gradient(
    (#1a2a6c 0 10%) (#b21f1f 30% 60%) (#fdbb2d 90% 100%),
    $direction: right
  );
}
```
```html
<div class="element sandbox large"></div>
```
</Example>

<Example caption="Make the stops meet and the transitions become hard edges.">
```scss
.element{
  @include gradient(
    (#1a2a6c 25%) (#b21f1f 25% 50%) (#fdbb2d 50% 75%) (orange 75% 100%),
    $direction: right
  );
}
```
```html
<div class="element sandbox large"></div>
```
</Example>

<Example caption="An angle works in any unit: `deg`, `turn`, `rad` or `grad`.">
```scss
.element{
  @include gradient(#f857a6 #5b86e5, $direction: 0.125turn);
}
```
```html
<div class="element sandbox large"></div>
```
</Example>

### Radial gradients

Everything `radial-gradient` did. Pass `radial` as the type, then a shape and a position if you want them.

<Example caption="A circle from the centre.">
```scss
.element{
  @include gradient(red orange, radial, $shape: circle, $position: center);
}
```
```html
<div class="element sandbox large"></div>
```
</Example>

<Example caption="An ellipse, which follows the shape of the box.">
```scss
.element{
  @include gradient(red orange, radial, $shape: ellipse, $position: center);
}
```
```html
<div class="element sandbox large"></div>
```
</Example>

<Example caption="Move the centre to a corner.">
```scss
.element{
  @include gradient(red orange gold, radial, $shape: circle, $position: top-right);
}
```
```html
<div class="element sandbox large"></div>
```
</Example>

<Example caption="Hard stops turn a radial gradient into rings.">
```scss
.element{
  @include gradient(
    (darkslateblue 0 10%) (white 10% 20%) (dodgerblue 20% 30%) (powderblue 30% 100%),
    radial,
    $shape: circle,
    $position: center
  );
}
```
```html
<div class="element sandbox large"></div>
```
</Example>

<Example caption="With named arguments the call reads like a sentence.">
```scss
.element{
  @include gradient(
    $colors: pink crimson,
    $type: radial,
    $shape: circle,
    $position: top
  );
}
```
```html
<div class="element sandbox large"></div>
```
</Example>

### Conic gradients

A conic gradient sweeps its colours round a centre, like the hand of a clock. Its stops are angles or percentages of a full turn.

<Example caption="A pie chart is three stops and no image.">
```scss
.chart{
  width: 180px;
  height: 180px;
  border-radius: 50%;
  @include gradient(
    (#43c6ac 0 45%) (#191654 45% 80%) (#fdbb2d 80% 100%),
    conic
  );
}
```
```html
<div class="chart"></div>
```
</Example>

<Example caption="A progress ring: the filled part is one stop, the track is the other, and a circle in the middle holds the number.">
```scss
.ring{
  display: grid;
  place-items: center;
  width: 160px;
  height: 160px;
  border-radius: 50%;
  @include gradient((#6366f1 0 72%) (#e0e7ff 72% 100%), conic);

  &::before{
    content: "72%";
    display: grid;
    place-items: center;
    width: 124px;
    height: 124px;
    border-radius: 50%;
    background: #fff;
    font: 600 28px/1 system-ui, sans-serif;
    color: #312e81;
  }
}
```
```html
<div class="ring"></div>
```
</Example>

<Example caption="A loading spinner: a conic sweep from transparent to colour, cut into a ring and turned.">
```scss
@keyframes spin{
  to{ transform: rotate(1turn); }
}

.spinner{
  width: 64px;
  height: 64px;
  border-radius: 50%;
  @include gradient(transparent #0ea5e9, conic, $from: 90deg);
  -webkit-mask: radial-gradient(circle, transparent 23px, #000 24px);
  mask: radial-gradient(circle, transparent 23px, #000 24px);
  animation: spin 0.9s linear infinite;
}
```
```html
<div class="spinner"></div>
```
</Example>

<Example caption="A colour wheel for a picker. Blending red to red the long way round the hue circle passes through every hue.">
```scss
.wheel{
  width: 180px;
  height: 180px;
  border-radius: 50%;
  @include gradient(red red, conic, $in: hsl longer hue);
}
```
```html
<div class="wheel"></div>
```
</Example>

### Repeating gradients

Set `$repeating: true` and the stops repeat until they fill the box, which is how patterns are made without a single image file.

<Example caption="Hazard tape, for a warning banner or a maintenance notice.">
```scss
.tape{
  display: grid;
  place-items: center;
  height: 64px;
  font: 700 18px/1 system-ui, sans-serif;
  letter-spacing: 0.1em;
  color: #111;
  @include gradient(
    (#facc15 0 20px) (#111 20px 40px),
    $direction: 45deg,
    $repeating: true
  );

  span{
    padding: 6px 14px;
    background: #facc15;
  }
}
```
```html
<div class="tape"><span>UNDER MAINTENANCE</span></div>
```
</Example>

<Example caption="The checkerboard design tools draw behind a transparent image. The pattern is one conic tile, repeated by background-size.">
```scss
.transparency{
  height: 200px;
  background-size: 24px 24px;
  @include gradient((#e5e7eb 0 25%) (#fff 25% 50%), conic, $repeating: true);
}
```
```html
<div class="transparency"></div>
```
</Example>

<Example caption="Ripples, for a map pin or a live indicator.">
```scss
.ripples{
  height: 200px;
  @include gradient(
    (#0f766e 0 2px) (#ccfbf1 2px 18px),
    radial,
    $shape: circle,
    $position: center,
    $repeating: true
  );
}
```
```html
<div class="ripples"></div>
```
</Example>


<Hint kind="info">

To layer a gradient over a photo, or use one as a `mask-image` or `border-image`, use the [gradientValue](/docs/gradient-value) function. It takes the same arguments and returns the gradient as a value.

</Hint>

## What it refuses

An argument that does not belong to the gradient's type stops the build, because the browser would ignore it and nothing would say so.

```scss
.element {
  @include gradient(red blue, $from: 45deg);
}
```
```text
Error: $from is for a conic gradient, and this one is linear.
```

A colour stop the browser drops stops the build too, since the whole gradient goes with it. A conic gradient's stops are angles or percentages, so a length is refused there.

```scss
.element {
  @include gradient((red 10px) blue, conic);
}
```
```text
Error: `(red 10px) blue` is not a valid $colors for `gradient`: in `red 10px`, `10px` is not an angle or a percentage, and a conic stop is placed by one. A browser drops the whole gradient.
```
