# Placeholder

<Member name="placeholder">

The **Placeholder Sass mixin** helps you style the **placeholder text** in an `<input>` or `<textarea>` element and generate cross-browser compatible CSS code.

</Member>

## Examples

<Example caption="Simply call the mixin and write your style rules.">
```scss
.element{
  @include placeholder{
    color: red;
  }
}
```
</Example>

<Example caption="When you call the mixin at the root of your stylesheet, it targets all the <code>&lt;input&gt;</code> and <code>&lt;textarea&gt;</code> elements.">
```scss
@include placeholder{
  color: orange;
}
```
</Example>
