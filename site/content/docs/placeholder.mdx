# Placeholder

<Member name="placeholder">

The **Placeholder Sass mixin** helps you style the **placeholder text** in an `<input>` or `<textarea>` element.

</Member>

## Examples

<Example caption="Called in a selector, the block styles that field's placeholder text and nothing else.">
```scss
.element {
  @include placeholder {
    color: #94a3b8;
  }
}
```
```html
<style>
  body { background: #f8fafc; font: 14px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; color: #0f172a; }
  .element { width: 100%; max-width: 340px; padding: 12px 14px; border: 1px solid #cbd5e1; border-radius: 12px; font: inherit; color: inherit; }
</style>
<input class="element" type="email" placeholder="you@example.com" />
```
</Example>

<Example caption="When you call the mixin at the root of your stylesheet, it targets all the `<input>` and `<textarea>` elements.">
```scss
@include placeholder {
  color: #a8a29e;
  font-style: italic;
}
```
```html
<style>
  body { background: #f8fafc; font: 14px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; color: #0f172a; display: grid; gap: 10px; max-width: 340px; }
  input, textarea { width: 100%; padding: 12px 14px; border: 1px solid #cbd5e1; border-radius: 12px; font: inherit; color: inherit; }
</style>
<input type="text" placeholder="Every field on the page" />
<textarea placeholder="This one as well" rows="2"></textarea>
```
</Example>

<Hint kind="info">

**Changed in Gerillass 4.0.0.** The mixin used to write five rules, the standard one and four prefixed ancestors. Measured in Chrome 152, Firefox 156 and Safari 26.6.2, by giving each selector a colour of its own and asking what actually painted: `:-ms-input-placeholder` and the single-colon `:-moz-placeholder` parse in none of the three, and `::-webkit-input-placeholder` and `::-moz-placeholder` are each their own engine's alias for `::placeholder`, which was written anyway. So one rule is left, and every browser since Chrome 57, Firefox 51 and Safari 10.1, all from 2017, understands it.

</Hint>

<Hint kind="warning">

**A placeholder can come out paler than the colour you set.** Firefox gives it an opacity of its own, so `opacity: 1` beside the colour is the usual answer.

</Hint>
