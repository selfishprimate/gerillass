# Placeholder

<Member name="placeholder">

The **Placeholder Sass mixin** helps you style the **placeholder text** in an `<input>` or `<textarea>` element.

</Member>

## Examples

<Example caption="Called in a selector, the block styles that field's placeholder text and nothing else.">
```scss
.element {
  @include placeholder {
    color: #657167;
  }
}
```
```html
<style>
  body { background: #fafaf8; font: 14px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; color: #657167; }
  .element { width: 100%; max-width: 340px; padding: 12px 14px; border: 1px solid #dee0cd; border-radius: 12px; font: inherit; color: inherit; }
</style>
<input class="element" type="email" placeholder="you@example.com" />
```
</Example>

<Example caption="For every field on the page, wrap the call in [All Text Inputs](/docs/all-text-inputs) rather than putting it at the root. The mixin writes the pseudo-element on the selector it is called in, so it needs one.">
```scss
@include all-text-inputs {
  @include placeholder {
    color: #657167;
    font-style: italic;
  }
}
```
```html
<style>
  body { background: #fafaf8; font: 14px/1.5 Inter, ui-sans-serif, system-ui, sans-serif; color: #657167; display: grid; gap: 10px; max-width: 340px; }
  input, textarea { width: 100%; padding: 12px 14px; border: 1px solid #dee0cd; border-radius: 12px; font: inherit; color: inherit; }
</style>
<input type="text" placeholder="Every field on the page" />
<textarea placeholder="This one as well" rows="2"></textarea>
```
</Example>

<Hint kind="warning">

**Changed in Gerillass 4.0.0.** The mixin used to write five rules, the standard one and four prefixed. Two of those parse in no browser at all and the other two are aliases for `::placeholder`, which was written anyway, so one rule is left: every browser since 2017 understands it.

</Hint>

<Hint kind="warning">

**A placeholder can come out paler than the colour you set.** Firefox gives it an opacity of its own, so `opacity: 1` beside the colour is the usual answer.

</Hint>

## What it refuses

The mixin writes `::placeholder` on the selector it is called in, so it needs
one. Until 4.0.0 a call at the root wrote `&::placeholder` and this page said
it styled every field. It does not. Measured in Chrome 152, Firefox 156 and
Safari 26.6.2, all three keep the rule and every placeholder stays its default
colour and upright, because a top-level `&` is `:scope`, which is the document,
and a document has no placeholder. Dart Sass 1.91 on the command line refuses
it outright, so the same call was a build error or dead CSS depending on how
the stylesheet was compiled.

```scss
@include placeholder {
  color: #657167;
}
```
```text
Error: `placeholder` styles the placeholder of the field it is called in, so call it inside a selector, such as `.field { @include placeholder { color: gray; } }`. At the root it wrote `&::placeholder`, which styles nothing in any browser. For every field at once, wrap it in `all-text-inputs`.
```

With no block there is nothing to put inside the rule, so Sass removed the rule
and the call did nothing and said nothing.

```scss
.element {
  @include placeholder;
}
```
```text
Error: `placeholder` wraps the styles you pass it, so call it with a block, such as `@include placeholder { color: gray; }`.
```
