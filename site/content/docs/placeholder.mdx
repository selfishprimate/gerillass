# Placeholder

<Member name="placeholder">

The **Placeholder Sass mixin** helps you style the **placeholder text** in an `<input>` or `<textarea>` element and generate cross-browser compatible CSS code.

</Member>

## Examples

<Example caption="Simply call the mixin and write your style rules.">
```scss
.element{
  @include placeholder{
    color: red;
  }
}
```
```html
<input class="element" type="text" placeholder="This placeholder is red" />
```
</Example>

<Example caption="When you call the mixin at the root of your stylesheet, it targets all the `<input>` and `<textarea>` elements.">
```scss
@include placeholder{
  color: orange;
}
```
```html
<input type="text" placeholder="Every placeholder on the page" />
<textarea placeholder="Including this one" rows="2"></textarea>
```
</Example>
