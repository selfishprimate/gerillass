# Border Box

<Member name="border-box">

The **Border Box** Sass mixin sets the [box-sizing CSS property](https://developer.mozilla.org/en-US/docs/Web/CSS/box-sizing) to `border-box` for the selected HTML elements. This keeps the padding and the border inside the element.

</Member>

## Arguments

<Arguments of="border-box" footnote="Please check out the links at the end of the page to learn more about box sizing.">
  <Argument name="$value" type="string">Accepts the <code>only</code> value. Use it when you want to apply the styles to one specific HTML element.</Argument>
</Arguments>

## Examples

<Example caption="Both boxes are 200px wide with 20px of padding and a 4px border. The mixin is on the lower one, so its 200px is the whole box; the upper one is the default `content-box` and ends up 248px wide.">
```scss
.element {
  @include border-box;
}
```
```html
<style>
  body { margin: 0; padding: 18px; background: #f2f2eb; font: 13px/1.4 Inter, ui-sans-serif, system-ui, sans-serif; color: #2f3937; }
  .box { width: 200px; padding: 20px; border: 4px solid #668f80; border-radius: 10px; background: #fff; }
  .control { box-sizing: content-box; }
  .box + .box { margin-top: 12px; }
  .box small { display: block; font-weight: 600; color: #657167; }
  .ruler { width: 200px; margin-bottom: 8px; border-top: 2px solid #db504a; font-size: 11px; font-weight: 600; color: #db504a; }
</style>
<div class="ruler">200px</div>
<div class="box control"><small>content-box</small>The padding and the border are added on.</div>
<div class="box element"><small>border-box</small>The padding and the border are inside the 200px.</div>
```
</Example>

<Example caption="Pass the `only` value as an argument to apply the style rules only to the selected element.">
```scss
.element {
  @include border-box("only");
}
```
</Example>

<Example caption="Call the mixin at the root of your stylesheet to target all the HTML elements.">
```scss
@include border-box;
```
</Example>

<Hint kind="warning">

**Changed in Gerillass 4.0.0.** Called inside a selector with no argument, the descendants are written inside `:where()`, so a `box-sizing` of your own for one of them wins where it used to lose. At the root of a stylesheet nothing changes.

</Hint>
