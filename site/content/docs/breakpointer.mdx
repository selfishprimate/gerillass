# Breakpointer

<Member name="breakpointer">

The **Breakpointer** Sass mixin pins a small badge to the corner of the page
naming the breakpoint you are at, so the width you are writing styles for is on
screen rather than in your head. The names come from the same map
[Breakpoint](/docs/breakpoint) reads, so the two always agree.

One line gets you a badge that is already legible and out of the way: fixed to
the top right, dark, above the page, and transparent to the pointer so it never
takes a click meant for what is under it. A block of your own overrides any of
that.

</Member>

<Hint kind="warning">

**This is for development only.** Take the call out before you ship, or the badge goes to production with you.

</Hint>

## Arguments

<Arguments of="breakpointer" footnote="A declaration block changes how the badge looks; it is written after the defaults, so anything in it wins.">
  <Argument name="$selector" type="string">A selector to hang the badge on instead of <code>body</code>, as a string. A selector list such as <code>".a, .b"</code> gets a badge on each. It is read only at the root of a stylesheet: called inside a selector the badge goes on that element, so an argument there is refused rather than ignored.</Argument>
</Arguments>

## Examples

<Example resizable hint="Drag the box: the badge names the frame's width rather than the window's, so it changes as you go." caption="One line, at the root of a stylesheet. The badge is pinned to the top right of the page and carries its own look, and it is `pointer-events: none`, so the close button it is sitting over still takes the click.">
```scss
@include breakpointer;
```
```html
<style>
  body { margin: 0; padding: 0; background: #fafaf8; font: 15px/1.6 Inter, ui-sans-serif, system-ui, sans-serif; color: #2f3937; }
  .bar { display: flex; align-items: center; justify-content: space-between; padding: 14px 18px; background: #fff; box-shadow: 0 1px 0 #dee0cd; }
  .bar b { font-size: 15px; }
  .bar a { color: #657167; text-decoration: none; font-weight: 600; }
  p { margin: 0; padding: 18px; max-width: 34em; color: #657167; }
</style>
<div class="bar"><b>Settings</b><a href="#">Close</a></div>
<p>The badge is over the Close link in the corner, and the link still works: the badge takes no pointer events.</p>
```
</Example>

<Example resizable hint="Drag the box: same badge, different corner and colour." caption="A declaration block dresses it. The defaults are written first, so a block only has to name what it wants changed, and anything it leaves alone stays as it was.">
```scss
@include breakpointer {
  top: auto;
  right: auto;
  bottom: 0;
  left: 0;
  border-radius: 0 4px 0 0;
  background: #ed6a5a;
  font-size: 14px;
}
```
```html
<style>
  body { margin: 0; padding: 18px; background: #222c25; font: 15px/1.6 Inter, ui-sans-serif, system-ui, sans-serif; color: #f2f2eb; }
  p { margin: 0; max-width: 34em; color: #8b9381; }
</style>
<p>Moved to the bottom left and recoloured. Only the five declarations that differ are written; the padding, the weight and the pointer behaviour come from the mixin.</p>
```
</Example>

<Example caption="At the root, a selector of your own takes the badge instead of `body`, which is how it goes on a debug bar you already have. A selector list gets one badge each.">
```scss
@include breakpointer(".debug");

@include breakpointer(".header, .footer");
```
</Example>

<Hint kind="warning">

**Changed in Gerillass 4.0.0.** The badge carries its own look. Until now the mixin wrote `content` and nothing else, so a bare call put the breakpoint's name in the page's own text flow at the top of `body` and pushed the page down by a line, and every project wrote the same block of positioning to get the badge described here. A block of your own still overrides every default.

</Hint>

## What it refuses

A selector is read only at the root, where there is no selector to attach the
badge to. Inside one the badge goes on that element, so an argument there used
to be dropped without a word.

```scss
.element {
  @include breakpointer(".debug");
}
```
```text
Error: `breakpointer` reads $selector only at the root of a stylesheet, where there is no selector to attach the label to. Called inside one the label goes on that element, so drop the argument, or move the call to the root.
```

An empty selector used to compile to a bare `::before`, which is `*::before`,
so the badge was drawn on every element on the page.

```scss
@include breakpointer("");
```
```text
Error: `breakpointer` was given an empty $selector, which would put the label on every element on the page. Pass a selector such as `".debug"`, or no argument at all to attach it to body.
```

And a selector has to be a string, since that is what goes into the stylesheet.

```scss
@include breakpointer(42);
```
```text
Error: `42` is not a valid $selector for `breakpointer`. Pass a selector as a string, such as `".debug"`, or no argument at all to attach it to body.
```
