# Text Selection

<Member name="text-selection">

The **Text Selection** Sass mixin helps you style the portion of text (or an element) that a user has selected.

</Member>

## Arguments

<Arguments of="text-selection">
  <Argument name="$value" type="string">Accepts the <code>only</code> value. Use it when you want to apply the styles to one specific HTML element.</Argument>
</Arguments>

## Examples

<Example caption="Select the text in the result below. If you call it inside a selector without passing a value, the style rules apply to that element and its children.">
```scss
.element{
  @include text-selection{
    color: pink;
    background-color: red;
  }
}
```
```html
<p class="element">Select this line, and the <strong>bolder part inside it</strong>, to see both change.</p>
```
</Example>

<Example caption="Select the text in the result below and compare it with the example above. Pass the `only` value as an argument to apply the style rules to only one specific HTML element.">
```scss
.element{
  @include text-selection(only){
    color: pink;
    background-color: red;
  }
}
```
```html
<p class="element">Select this line, and the <strong>bolder part inside it</strong>. Only the line changes.</p>
```
</Example>

<Example caption="Call the mixin at the root of your stylesheet to target every element on the page. Select either line in the result below.">
```scss
@include text-selection{
  color: pink;
  background-color: red;
}
```
```html
<p class="element">Select this line,</p>
<p>and this one, which carries no class at all.</p>
```
</Example>
